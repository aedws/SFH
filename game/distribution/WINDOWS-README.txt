SFH Windows 다운로드판 · 실행과 자동 저장

1. ZIP을 전부 풀고 SFH.exe를 실행하세요. SFH.pck를 같은 폴더에 두세요.
2. 거점에서 세팅을 저장하고, 작전에서 탈출하면 획득 재화·창고·해금·성장이 이어집니다.
3. 저장 위치: %APPDATA%\Godot\app_userdata\SFH\
   Windows 탐색기 주소창에 위 경로를 붙여 넣으세요.

세팅 저장: 거점 가방 배치, 무기·방어구, 모듈·고유 파츠와 강화 상태.
진행 저장: 영구 크레딧, 창고, 해금·제작·도감, 외부 성장, 로컬 랭킹과 최근 100회 작전 이력.
거점의 작은 저장 상태 안내에서 저장 결과를 확인할 수 있습니다. 마우스를 올리면 위치와 최근 기록을 봅니다.
편집 중 저장하지 않은 초안은 저장되지 않습니다. 변경 확인 창에서 저장을 선택하세요.

작전 중 게임을 종료하면 진행 중인 방·적·임시 버프는 이어지지 않습니다.
미반출 전리품은 지급되지 않으며, 이미 지불한 투입 비용과 장착 장비에는 기존 실패 규칙을 적용합니다.
성공 반출 장비는 기존 정산 규칙에 따라 창고에 보관합니다. 가방과 창고에 두 번 지급하지 않습니다.

업데이트: 새 ZIP을 다른 폴더에 풀어도 같은 Windows 계정이면 저장을 불러옵니다.
백업: 게임을 완전히 종료하고 위 SFH 저장 폴더 전체를 다른 곳에 복사하세요.
복원/PC 이전: 게임 종료 후 백업 폴더를 같은 위치에 복사하세요. 서로 다른 실행 버전을 동시에 켜지 마세요.
sfh_profile.json, sfh_meta_progression.json, sfh_desktop_progress.json은 이전 정상본 .bak도 유지합니다.
손상된 주 파일은 정상 백업으로 복구하고, 지원하지 않는 새 형식은 덮어쓰지 않습니다.
저장 오류가 표시되면 게임 종료 전 여유 공간·폴더 쓰기 권한을 확인하고 폴더를 백업하세요.
안전한 이전 상태를 불러올 때 가장 최근 변경 일부는 손실될 수 있습니다.

클라우드 동기화·브라우저 저장 가져오기·전투 도중 이어하기는 지원하지 않습니다.
이 저장은 로컬 프로토타입용이며 치트 방지/서버 권위 저장이 아닙니다.
BUILD-METADATA.json의 커밋·Godot·CSV 버전과 ZIP의 SHA-256으로 배포 버전을 확인하세요.
