# Nanum Gothic

SFH uses `NanumGothic-Regular.ttf` as the project-wide Godot fallback font so
Korean UI text renders consistently in desktop and Web exports.

- Source: https://github.com/google/fonts/tree/main/ofl/nanumgothic
- License: SIL Open Font License 1.1 (`OFL.txt`)
- SHA-256: `76F45EF4A6BCFF344C837C95A7DCC26E017E38B5846D5AE0CDCB5B86BE2E2D31`

Keep the font and its license file together when redistributing the game.
