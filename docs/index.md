# SFH 개발 위키

SFH는 Godot 4로 만드는 모듈형 탑다운 뱀서라이크입니다.

이 위키는 Godot을 처음 사용하는 개발자도 검색을 통해 다음 행동을 찾을 수 있도록 작성합니다.

## 검색 방법

상단 검색창을 클릭하거나 `/` 키를 누른 뒤 원하는 단어를 입력합니다.

검색할 때는 기능 이름뿐 아니라 증상도 입력할 수 있도록 문서를 작성합니다. 예를 들어 `플레이어`, `이동`, `WASD`, `캐릭터가 움직이지 않음`은 같은 관련 문서에서 찾을 수 있습니다.

## 문서 작성 원칙

1. 기능에는 대응하는 문서가 있어야 합니다.
2. 문서는 목적, 사용법, 의존성, 제거 방법을 포함합니다.
3. 오류 메시지와 검색 별칭을 본문에 기록합니다.
4. 중요한 구조 변경은 결정 기록으로 남깁니다.
