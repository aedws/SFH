# SFH 개발 현황

SFH는 Godot 4 기반의 **모듈형 탑다운 뱀서라이크 + 익스트랙션 슈터**입니다. 이 첫 화면은 공동 작업자가 위키만 열어도 현재 상태, 최근 변경, 다음 작업을 파악할 수 있는 개발 대시보드입니다.

## 현재 한눈에 보기

| 구분 | 상태 | 요약 |
|---|---:|---|
| 실행 가능한 세로 단면 | ✅ 플레이 가능 | 작전 선택 → 자동 전투·파밍 → F 탈출 또는 사망 |
| 소·중·대형 랜덤 맵 | ✅ 완료 | 투자 등급별 방 수, 실내 벽·기둥, 미니맵 포함 |
| 캐릭터 장비 기반 | ✅ 완료 | 메인·보조 무기 태그, 스킬 호환, 방어구 스탯 |
| 가방·장비 개조 기반 | ✅ 9/9 | 가변 격자, I/U UI, 파츠·모듈·강화·개조 |
| 자동 검증 | ✅ 통과 | 전체 작전 진입과 신규 장비·인벤토리 계약 검사 |
| 영속 경제·제작 재료 | ⏳ 예정 | 비용·재료 정책 확정 뒤 별도 모듈로 연결 |

!!! info "진행률을 읽는 기준"
    숫자는 게임 전체 완성도가 아니라 **해당 기능 묶음의 현재 합의된 최소 구현 항목** 기준입니다. 범위가 바뀌면 분모와 완료 조건도 [개발 현황과 업데이트](development-status.md)에 함께 기록합니다.

## 검색 요령

상단 검색창 또는 `/` 키를 사용합니다. 기능명뿐 아니라 `I키`, `U키`, `가방`, `칸`, `장착 코스트`, `소분류`, `고유 파츠`, `개조 태그`, `진행률`, `버그픽스` 같은 증상·규칙 단어로도 찾을 수 있습니다.

문서 변경은 **목적 → 현재 상태 → 사용법 → 의존성 → 제거·확장 지점 → 검색 별칭** 순서로 기록합니다. 중요한 구조 변경은 결정 기록 또는 모듈화 점검 기록에도 남깁니다.
