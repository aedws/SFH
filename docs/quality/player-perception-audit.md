# 플레이어 인식 단위 E2E 감사

## 2026-09-07 · FUN QA 1차 · 선택→교전→회수 {#fun-qa-affordance}

최신 GDD/66행 트래커는 해시 변경이 없습니다. 판단 없이 남은 신규 미구현은 없으며, 미구현6건은 파우치2·심층3·혈전1의 오너 결정에 묶여 있습니다. 이번에는 정책을 임의 확정하지 않고 **안내를 믿고 행동했을 때 결과가 일치하는지** 검사했습니다. 코드 대응도78.5%는 유지합니다.

| 순간 | 관찰과 수정 | 판정 |
|---|---|---|
| 출격 선택 | 카드에 방 수까지 압축해 말줄임 발생 → 규모/시간/비용 두 줄과 선택 상세 분리 | 첫 표시·5폭 계약, Web1280 실물 가독성 확인 |
| 탈출 경계 | 몸만 걸쳐도 F 시작 안내, 중심은 범위 밖이라 거부 → 안으로 이동 안내·보이는 원·실제 판정 통일 | 실제 물리 겹침/F·일시정지/복귀·잠금·반경 변경 계약 통과 |
| 방 전투 | 좌클릭+자기장으로 14처치 후 봉쇄 문이 열리고 현장 드랍/보상 생성 | 일반 Web 입력 확인; 실전에서 훈련 문구 없음 |
| 성장 | 처치 뒤 이동해 XP 회수, 3장 중 화력 과부하 선택 후 레벨2·전투 복원 | 작전 한정 효과와 숫자 변화 확인 |
| 회수 | 현장 F로 전도 룬 장착, 보상 상자 F로 CR0→31·회수 안내 | 효과/보유 HUD와 경제 피드백 확인 |

**조건:** 수정된 로컬 Web 릴리스, 새 격리 Chromium/1280×720, 기본 체력·이동·장비, 키보드/마우스 입력. 약5분26초에 검수를 종료했고 브라우저 오류는0입니다. 자동 조작 사이 대기 시간이 포함되며 소형 한 방 중심의 검사입니다. 스크린샷은 로컬 QA 산출물 `sfh-fun-qa-web-20260907/briefing-readable.png`, `room-reward.png`에 보관합니다. 상태 주입 E2E나 공개 배포 완료로 혼동하지 않습니다.

### 다음 FUN QA 수락

1. 중·대형/Windows에서 10분 일반 입력과 실제 탈출까지 이어가고, 기존 간헐 F 실패를 별도 재현합니다. 이번 경계 수정만으로 과거 원인을 확정하지 않습니다.
2. 첫 방 클리어 직후 다음 동선·드랍 의미가 즉시 이해되는지 확인합니다. 이번 화면의 `방21/24`와 `LOOT·G1/G2`는 초보자가 진행도/아이템 종류로 오해할 여지가 있어 다음 관찰 질문으로 남깁니다.
3. 룬 장착 후 하단 소켓의 빈 슬롯·말줄임과 키 도움말 밀도를 작은 화면에서 비교합니다. 기능 정상과 정보 인식 합격을 나눕니다.
4. 첫 출격202ms 지연, 이동 반응·교전 공백·타격 구분을 실시간 관찰합니다. 이번 무입력 대기를 전투 밸런스 문제나 재미 부족의 확정 근거로 사용하지 않습니다.

자동 인과 E2E 31체크포인트/15흐름, 상점 견적·실물, 어댑터 계약을 통과했습니다. 소스 GPU 120초는 약59.8FPS이나 **모든 부분 구현 완료·사람 재미 합격은 아직 선언하지 않습니다.** 남은 한 행은 배포판/첫 출격 지연 QA입니다.

### 실행 증거와 판정 경계

- 코드 `cd25dfe`: PC 선택→거점 이동→F 게이트→중형 브리핑→작전→마우스 공격·2스킬→12처치·드랍→사망(02:02)→Enter 거점→I 가방을 실제 Web 릴리스 입력으로 확인했습니다. HP/속도/좌표를 주입하지 않았습니다. 관찰 중 대기 시간이 포함되어 난이도나 재미 수락 근거로 사용하지 않습니다.
- Windows 로컬 릴리스: 개인 저장과 다른 `SFH-QA-partial-20260907` 디렉터리로 PC→거점→I→아이템 선택/R 회전 충돌 안내→닫기를 확인했습니다. 실행 파일과 Web PCK 모두 내보낸 리소스 부팅 검사를 통과했습니다. 이는 Windows 10분 완주 증거가 아닙니다.
- `release_boot_contract_test.gd`: 내보낸 Resource 복제·거점/플레이어·중형 진입·훈련 문구 배제·일시적 HUD 줄바꿈 복구·물리 카메라를 검사합니다. 렌더 모드에서는 화면 내 투영과 청록 플레이어 픽셀 40개 이상도 검사합니다. 로컬 5FPS 제한에서 374픽셀 통과. 5FPS는 안정성 스트레스 조건이며 권장 프레임 수치가 아닙니다.
- CI: 소스 테스트에 더해 Web/Windows PCK 검사, Xvfb 저프레임 렌더 게이트를 배포 전에 배치했습니다. Linux의 PCK 검사는 Windows 네이티브 실행이나 실제 WebGL 검수를 대체하지 않습니다.
- **다음 수락 작업:** 중·대형 10분 일반 플레이의 양 플랫폼 동등성, 간헐 탈출 F 입력 재현, 첫 출격202ms 지연 분리. 작은 작전 규모 카드의 말줄임은 상단 FUN QA에서 수정·재검증했습니다. 상태값/로그 통과와 실제 화면·입력 통과를 별도 기록합니다.

재미를 더 선명하게 만드는 **승인 전 개선안**은 [한 판의 다섯 순간 제안서](five-moment-fun-proposal.md)에 별도로 정리합니다. 아래 자동 검사 통과와 인간의 재미 검증은 같은 판정이 아닙니다.

기능이 호출됐다는 사실만으로 플레이가 정상이라고 판정하지 않습니다. SFH E2E는 플레이어가 **지금 어디에 있고, 무엇을 선택할 수 있으며, 입력이 어떤 결과를 냈고, 다음에 무엇을 해야 하는지** 화면에서 이해할 수 있어야 통과합니다.

## 현재 자동 검증 범위

`PlayerPerceptionJudge`는 보이는 Label·Button의 실제 문자열을 수집합니다. 상위가 숨겨진 노드는 증거로 인정하지 않으며 깨진 문자, `NaN`, `<null>`, 의미 단서 누락을 실패로 처리합니다. 실제 입력 전후 문구·숫자·월드 이동량도 함께 비교합니다.
