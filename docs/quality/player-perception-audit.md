# 플레이어 인식 단위 E2E 감사

기능이 호출됐다는 사실만으로 플레이가 정상이라고 판정하지 않습니다. SFH E2E는 플레이어가 **지금 어디에 있고, 무엇을 선택할 수 있으며, 입력이 어떤 결과를 냈고, 다음에 무엇을 해야 하는지** 화면에서 이해할 수 있어야 통과합니다.

## 인식 단위

| 인식 단위 | 플레이어 질문 | 자동 판정 예시 |
|---|---|---|
| 방향 | 지금 어디에서 무엇을 해야 하나? | 거점명·작전 게이트·이동 및 메뉴 키가 동시에 읽힘 |
| 선택 | 무엇을 비교하고 바꿀 수 있나? | 가방 공간, 장비 슬롯, 모듈 코스트, 키 설정 범위 표시 |
| 결정 | 투입하면 무엇을 지불하고 무엇을 기대하나? | 지역·난이도·규모·위험·회수·소모품·투입 버튼 표시 |
| 한눈 정보 | 전투 중 즉시 알아야 할 상태는 무엇인가? | 임무·HP·XP·에너지·스킬·대시·미니맵이 아이콘·숫자 중심으로 한 화면에 존재 |
| 행동 피드백 | 방금 입력이 적용됐나? | Q 현재 무기명, 점멸 이동·자원·쿨타임, 대시 궤적·카메라 리드·상태 변경 |
| 자원 피드백 | 회수로 무엇이 늘었나? | F 전후 코인 아이콘 옆 `CR` 숫자 증가 |
| 상태 피드백 | 탈출 상태가 왜 멈추거나 다시 움직이나? | 시작·일시정지·재개와 잔여 시간 문구 구분 |
| 결말 | 성공과 실패가 무엇을 남기거나 잃게 했나? | 생존·처치·정산 또는 분실과 거점 복귀 입력 표시 |
| 연속성 | 메뉴나 결과 뒤 원래 맥락으로 돌아왔나? | 전투 HUD 또는 거점 안내가 다시 완전하게 복원 |

## 현재 자동 검증 범위

`PlayerPerceptionJudge`는 보이는 Label·Button의 실제 문자열을 수집합니다. 상위가 숨겨진 노드는 증거로 인정하지 않으며 깨진 문자, `NaN`, `<null>`, 의미 단서 누락을 실패로 처리합니다. 실제 입력 전후 문구·숫자·월드 이동량도 함께 비교합니다.

| 플레이 여정 | 인식 체크포인트 | 자동 상태 |
|---|---:|---|
| 첫 거점 방향 파악 | 거점·게이트·I/U/E/Q/F/K 안내 | 통과 |
| 키 설정 | 범위·저장·ESC·기본값 복원 | 통과 |
| 가방·장비·개조 | 공간·슬롯·호환·코스트·적용 수치 | 통과 |
| Q 무기 교체 | 활성 슬롯 변경 + 거점 `현재 무기` 문구 변경 | 통과 |
| 작전 결정 | 비용·회수·위험·소모품·명시적 투입 | 통과 |
| 타겟 파밍 결정 | 지역·난이도별 대표 전리품·후보 수·최고 등급과 동일 seed 결과 | 통과 |
| 전투 첫 시선 | 임무·HP·XP·에너지·스킬·대시·미니맵 | 통과 |
| 1번 점멸 | 실제 이동 + 에너지 감소 + 재사용 표시 | 통과 |
| Space 대시 | 실제 입력 + 쿨타임·READY 변경 + 청록 궤적·카메라 방향 리드 | 통과 |
| 마우스 기본기 | 물리 좌클릭 + 발사체·타격·치명타격·처치·드랍 수치 증가 | 통과 |
| 방 전투 | 방 진입 봉쇄 문구 + 적·문 생성 + 확보·보상·내부 경험치 증가 | 통과 |
| 현장 전리품 판단 | 후보·현재 무기·소유 수량·탈출/사망 결과 비교 + `ESC` 보류 + 재접근 `F` 획득 | 통과 |
| 런 세션 소켓 | F 런 소켓 장착·RUN ONLY·점유 슬롯 + 실제 무기 피해 증가 + HUD 해제 원복 | 통과 |
| 방·통로 안개 | 방/문턱 유예/퇴장/통로/입장/방 6단계 + 안심 외곽 + 다른 방 차폐 + 전체 미니맵 독립 | 통과 |
| 중·대형 10분 | 599초 잠금 + 600초 개방 + HUD 10:00 + 세션 유지 | 통과 |
| 내부 증강 선택 | 3장 계열·이름·중첩·효과 비교 + 실제 `2` 선택 + 전투 복원 | 통과 |
| 전투 중 I/U/E | 모달 종료 뒤 전투 정보 전체 복원 | 통과 |
| F 자원 회수 | 휴대 크레딧 수치 증가와 표시 갱신 | 통과 |
| 탈출 방어 | 시작·이탈 일시정지·복귀 재개 문구 | 통과 |
| 성공·실패 | 서로 다른 정산/분실 결과 + 두 차례 거점 복귀 | 통과 |

현재 한 번의 E2E는 **23개 UI 상태 전환**, **28개 플레이어 인식 체크포인트**, **10개 게임플레이 인과 흐름**, **9개 인식 단위**를 연속 판정합니다.

## 부족한 부분과 다음 순서

1. **P1 · 중형·대형 실제 동선 장기 주행** — 가속 논리 시계 다음으로 이동 불가 방·막힌 통로·탈출 접근성과 실제 체류 밀도를 실기 세션으로 측정합니다.
2. **P1 · 전장의 안개 렌더링 미감** — 자동화된 6단계 상태 위에 1366×768 포함 실제 화면의 경계 밝기와 끊김을 육안 판정합니다.
3. **P1 · P4-06 정산 인과** — 성공 시 세션 자산 자동 환전·도면 영구 해금, 사망 시 런 전리품 소실과 중복 정산 방지를 실제 결과 화면까지 연결합니다.
4. **P2 · 다중 해상도·저사양 실기** — 1366×768·1600×900·브라우저 가로 화면과 최소 목표 GPU에서 글꼴·HUD·1% Low를 기록합니다.
5. **P2 · 사운드 인지 계층** — 기본기·피격·위험·회수·탈출을 화면을 보지 않아도 구분할 최소 사운드 계약을 설계합니다.

이 목록에서 `부분 자동`과 `수동 필요`는 기능 미구현과 구분합니다. 기능이 있어도 플레이어 경험을 자동으로 보증하지 못하면 완료로 닫지 않습니다.

## 실행

