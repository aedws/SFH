# P7 이후 사전 구현 설계

!!! warning "번호 체계"
    공개 [SFH Master GDD](https://wobbly-pawpaw-1ff.notion.site/SFH-6b45b728004082af8a4a811ef0a1c5e9)의 공식 구현 마일스톤은 **Phase 1~6**입니다. 이 문서의 P7~P10은 기획 원문에 없는 새 Phase를 확정하는 것이 아니라, Phase 1~6 완료 뒤 남는 상세 요구를 추적하기 위한 **저장소 내부 후속 작업 ID**입니다.

## 2026-09-02 갱신 근거

- 공개 원문: root `v1005`, 77블록, SHA-256 `67f9bef85449…`
- 새로 구체화된 범위: 런 종료 회전 상점, 손상·표준·고성능 3대 매물, 골드 리롤, 설계도 영구 제작 등록, 맞춤 옵션·소켓 제작, 단일·밀집 훈련 더미, DPS·타격·AP·쿨타임 계측, 무비용 자유 세팅, 도감 해금률·지역 힌트
- 공식 Phase 5 문구도 `창고·상점 리롤·제작소·연습장 + 준비 세션 UI`로 확대됐습니다. 따라서 이 기능들의 최소 연결은 먼저 P5 완료 조건에 포함하고, P7+에서는 경제 깊이·반복성·운영 품질을 완결합니다.
- Notion 체크박스 6개는 확정 범위 신호일 뿐 구현 완료 증거로 사용하지 않습니다.

## 착수 게이트

`P5 완료 → P6 완료 → P7 로비 경제 → P8 훈련장 → P9 도감·프리셋 → P10 출시 후보 회귀`

P5·P6가 끝나기 전에는 P7 코드를 조립하지 않습니다. 다만 데이터 열, 모듈 경계, 플레이어 인식 E2E, 기획 요청 ID는 미리 준비할 수 있습니다.

| P7-01 | 손상·표준·고성능 매물 | 정의·품질 정책·카탈로그 제공자 분리 | 실제 목록이 필요할 때 `ShopOffer` Sheet 추가 | 가격·성능·위험을 구매 전에 비교 |

## P10 · 출시 후보 운영 검증

- 신규 프로필에서 무료 복구→유료 출격→정산→상점·제작→훈련→도감까지 끊김 없이 이어집니다.
- Web·Windows는 동일 커밋·PCK·CSV 해시를 사용하고 모바일은 같은 Input Action을 터치로 전달합니다.
- 실패·취소·중복 입력은 자산을 이중 차감·지급하지 않습니다.
- 평균 PC·대형 교전 60 FPS 예산, 모듈 제거, 위키 링크·검색·모바일 접근성 검사를 함께 통과합니다.

## 데이터와 과금 경계

- 새 아이템·상점 매물·레시피·훈련 시나리오·도감 항목처럼 **목록이 실제로 필요할 때만** Google Sheet를 확장합니다.
- 1행 변수명·2행 설명·3행 이후 데이터, 실시간 시험→확정 CSV 전환 구조를 그대로 유지합니다.
- 임시값은 `provisional`과 결정 ID를 기록하며 확정값처럼 표시하지 않습니다.
- 결제, 유료 재화, Cloudflare 유료 플랜 활성화는 P7+ 범위가 아닙니다.

## 기계 검증

`docs/assets/post-p7-roadmap.json`이 원문 버전·블록 근거·패킷 ID·데이터 게이트·모듈·플레이어 결과·E2E 인과를 보관합니다. `scripts/check-p7-roadmap.ps1`은 공개 Notion 스냅샷과 불일치하거나 완료로 오표시된 패킷을 위키 빌드에서 차단합니다.
