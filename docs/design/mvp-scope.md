# MVP 범위

## 반드시 포함

- 플레이어 8방향 이동
- 카메라 추적
- 적 생성과 플레이어 추적
- 접촉 피해와 체력
- 가장 가까운 적을 향한 자동 공격
- 적 체력과 사망
- 경험치 드롭과 획득
- 레벨업 선택지
- 생존 시간과 처치 수 HUD
- 플레이어 사망과 재시작

## 첫 MVP에서 제외

- 완성형 그래픽과 애니메이션
- 온라인 기능
- 복잡한 저장 시스템
- 캐릭터 다수
- 업적과 도감
- 모바일 조작
- 고급 최적화

## 완료 조건

임시 그래픽만 사용해도 시작, 성장, 사망, 재시작으로 이어지는 한 판을 플레이할 수 있어야 합니다.
