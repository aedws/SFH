# Master GDD 구현 대조

## 기준 원문

- 권위 원본: [게시된 SFH 프로젝트 Master GDD](https://wobbly-pawpaw-1ff.notion.site/SFH-6b45b728004082af8a4a811ef0a1c5e9)
- 확인일: 2026-09-01
- 원문 상태: `0. 기술 스택`부터 `8. Godot 프로토타입 구현 마일스톤`까지 게시됨
- 확정도: 현재 렌더링 본문에는 `(미확정)` 표기가 없으므로 전 항목을 확정 요구로 판정

진행률은 Notion의 문장 존재 여부가 아니라 저장소의 코드·데이터·자동 검증을 근거로 계산합니다. 프로토타입에 유사 기능이 있어도 원문이 요구한 플레이 흐름이 연결되지 않으면 부분 완료로 처리합니다.

## 2026-09-01 핵심 변경

이전 공개안보다 다음 범위가 구체화되거나 새로 확정되었습니다.

1. **완전 자유 스킬 바인딩:** 키 자체의 재설정을 넘어 원하는 스킬을 마우스·Space·Q·E·숫자 키 등에 1:1로 배치합니다.
2. **로비 4대 세팅:** 캐릭터, 주·보조무기, 스킬, 유틸리티를 각각 투자 대상으로 선택합니다.
3. **전리품 2대 분류:** 무기·스킬·도면은 현장 교체와 영구 해금으로, 룬·코어·유물은 세션 소켓과 탈출 시 자동 환전으로 순환합니다.
4. **비동기 랭킹·시즌 보상:** 로컬 기록이 아니라 동일 조건 서버 집계와 주간 칭호·오라 보상을 요구합니다.

## 2026-09-01 원문 재확인 스냅샷

공개 Notion 페이지를 다시 렌더링해 `0. 기술 스택`부터 `8. Godot 프로토타입 구현 마일스톤`까지 확인했습니다. 이전 대조 이후 문장 삭제·신규 장·`(미확정)` 표기 추가는 발견되지 않았으며, 확정 요구 범위와 가중치는 그대로입니다. Notion의 Phase 1~6 체크박스는 현재 모두 체크되어 있어 기획 범위 확정 신호로 사용하되, 코드 완료 판정은 대신하지 않습니다. 완료 여부는 아래 저장소 근거와 플레이어 인식 E2E로 다시 판정합니다.

이번 재확인에서 가중 진행률은 **78%**입니다. P4-04A/B 현장 무기·스킬 교체와 안전 복구를 전리품 플레이 흐름에 연결한 근거를 반영했습니다. 배포 분리·Private 복구망은 개발 안전성과 협업 지속성을 높이는 기반 작업이지만 게임 기능 요구를 새로 완료한 것은 아니므로 GDD 기능 진행률에 가산하지 않습니다.

## 확정 요구 대조표

| 기획 묶음 | 가중치 | 구현률 | 저장소 근거와 남은 차이 |
|---|---:|---:|---|
| 기술 스택·모듈 기반 | ×1 | 100% | Godot 4.x, GDScript, CharacterBody2D·Area2D·TileMapLayer·Custom Resource와 기능별 Scene 경계 구현 |
| 입력·완전 자유 스킬 바인딩 | ×2 | 100% | 22개 Action 물리 키와 스킬→Action 배치를 분리하고 K UI·충돌 교환·HUD/발동·저장까지 연결 |
| 스마트 오토 타게팅 | ×2 | 95% | 최근접·최고 HP·엘리트·밀집 중심·이동 벡터·자기 대상 정책 구현. 콘텐츠별 튜닝이 남음 |
| 로비 인베스트먼트·타겟 파밍 | ×2 | 65% | 맵 크기·지역·난이도·페널티·상점·소모품 구현. 캐릭터 선택, 완성형 무기·스킬·유틸리티 투자 UI는 미완료 |
| 전리품 2대 분류·현장 파밍 | ×2 | 40% | 생명 주기·지역 테이블·현장 비교/획득·무기/스킬 즉시 교체와 거점 복구 구현. 세션 룬/코어/유물 소켓과 탈출 자동 환전은 미완료 |
| 가변 태그·등급 확장 | ×1 | 80% | 동적 태그, 1~5 등급, 불일치 스킬 비활성, 등급별 메커니즘 변형 구현. 무기별 독립 스킬 프리셋은 미완료 |
| 탈출·생환·파산 방지 | ×2 | 95% | F 방어전, 구역 이탈 일시정지·재개, 성공·사망 정산, 무료 기본 진입 구현. 신규 룬 환전 계약 연결이 남음 |
| 비동기 조건부 랭킹·시즌 보상 | ×1 | 40% | 동일 조건과 3대 지표의 로컬 랭킹 구현. 서버 제출·검증·신원·부정 방지, 주간 칭호·오라 보상은 미완료 |

계산식은 `Σ(구현률 × 가중치) ÷ 13`입니다.

`(100×1 + 100×2 + 95×2 + 65×2 + 40×2 + 80×1 + 95×2 + 40×1) ÷ 13 ≈ 78%`

Master GDD 확정 범위를 유지한 상태에서 자유 스킬 배치로 72%에서 75%, 현장 무기·스킬 교체로 78%까지 상승했습니다. Phase 4 자체는 P4-05 세션 소켓과 P4-06 자동 환전이 끝나기 전까지 완료로 표시하지 않습니다.

## 마일스톤 판정

| Phase | 판정 | 완료를 막는 차이 |
|---|---|---|
| Phase 1 · 이동·타게팅·자유 바인딩 | 완료 | 물리 키·스킬 위치를 별도 편집하고 HUD·실제 발동·저장에 반영 |
| Phase 2 · Q·태그·AP·쿨타임 | 완료 | 신규 장비·스킬 콘텐츠 튜닝만 후속 |
| Phase 3 · 탈출 방어·정산 | 완료 | Master GDD 핵심 흐름과 자동 검증 연결 |
| Phase 4 · 현장 교체·룬 소켓·환전 | 진행 중 | 현장 드랍·비교·보류·획득과 무기/스킬 즉시 교체·안전 복구 완료. 세션 전용 소켓과 자동 환전은 미완료 |
| Phase 5 · 로비 4대 세팅·계약·상점 | 부분 완료 | 계약·페널티·상점은 있으나 캐릭터·무기·스킬·유틸리티 선택 흐름이 불완전 |
| Phase 6 · 비동기 랭킹·시즌 보상 | 로컬 기반만 완료 | 온라인 제공자와 시즌 보상 계층이 없음 |
