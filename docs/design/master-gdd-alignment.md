진행률은 저장소 코드·데이터·플레이어 인식 E2E를 근거로 계산합니다. **공개 원문의 Phase 1~6은 현재 0/6 체크**입니다. 이전 파서가 문자열 `No`를 참으로 취급해 6/6로 안내했던 오류를 정정했습니다. 체크 여부는 기획자의 수동 표식일 뿐, 기능의 확정도나 코드 완료를 대신하지 않습니다. root v1005·77블록은 그대로이고 해시 변경은 체크값 정규화 수정 때문입니다.

## 2026-09-02 핵심 변경

이전 v797·57블록에서 v1005·77블록으로 확대되며 다음이 구체화됐습니다.

1. **3단계 플레이어 동선:** 로비 허브→출격 준비→인게임 던전의 역할을 분리했습니다.
2. **로비 허브 서비스:** 개인 창고, 런 종료 회전 상점, 설계도 제작소, 훈련 연습장, 도감·랭킹을 명시했습니다.
3. **상점 3대 매물:** 손상 하자품, 표준 순정품, 고성능 꿀매물의 가격·성능 스펙트럼과 골드 리롤을 확정했습니다.
4. **제작소 고점:** 설계도 영구 등록, 맞춤형 옵션·소켓 제작을 상점과 다른 확정 파밍 경로로 분리했습니다.
5. **훈련 연습장:** 단일 보스·밀집 잡몹 더미, DPS·타격·AP·쿨타임 계측, 무비용 자유 세팅을 요구합니다.
6. **도감:** 해금 진행률과 미해금 항목의 드랍 지역 힌트를 로비에서 확인합니다.
7. **공식 Phase 5 확대:** `로비 1단계 허브 + 2단계 준비 세션 UI` 연결까지 완료 조건에 포함됐습니다.

| 스마트 오토 타게팅 | ×2 | 95% | 최근접·최고 HP·엘리트·밀집 중심·이동 벡터·자기 대상 정책 구현, 콘텐츠별 튜닝 잔여 |
| 로비→준비→인게임 3단계 루프 | ×2 | 100% | 캐릭터·무기·스킬·유틸리티를 한 초안으로 견적하고 단 한 번 확정 결제한 뒤 허브→작전→정산→허브로 복귀 |
| 상점 vs 제작소 경제 | ×1 | 100% | 3대 품질 회전 매물·유료 리롤과 영구 등록 설계도·재료·랜덤 옵션·소켓 제작을 독립 서비스로 연결 |
| 훈련 연습장 | ×1 | 100% | 단일·밀집 시나리오, DPS·최대 타격·AP·쿨타임 계측, 무비용 세팅 복구 계약과 허브 진입 UI 연결 |
| 전리품 2대 분류·현장 파밍 | ×2 | 100% | 생명 주기·지역 테이블·현장 교체·세션 소켓·성공/사망 정산 완료 |
| 가변 태그·등급 확장 | ×1 | 85% | 동적 태그, 1~5 등급, 불일치 스킬 비활성, 등급 변형과 제작 옵션 풀 구현. 무기별 독립 스킬 프리셋은 P9 후속 |
| 탈출·생환·파산 방지 | ×2 | 95% | F 방어전, 구역 이탈 일시정지·재개, 정산, 무료 기본 진입 구현 |
| 비동기 조건부 랭킹·시즌 보상 | ×1 | 75% | 3대 로컬 랭킹·보스 격파, 검증 제출·재시도, P6-03 로컬 시즌 기간·참여·마감 기록 구현. 실서비스 계정·서버 시즌·칭호/오라 미완료 |

계산식은 `Σ(구현률 × 가중치) ÷ 15`입니다.

`(100×1 + 100×2 + 95×2 + 100×2 + 100×1 + 100×1 + 100×2 + 85×1 + 95×2 + 75×1) ÷ 15 = 96.3% → 96%`

9월 3일 체크박스 정정은 수동 표식을 고친 것으로 96% 계산을 올리거나 내리지 않습니다. P6-03 로컬 시즌은 완료했지만 실서비스 운영·보상은 아직 없으므로 해당 묶음의 75%를 보수적으로 유지합니다. 이 수치는 출시 준비율이 아닌 기능 가중 추정치입니다.

2. **내부 P7~P10:** 공식 Phase 1~6 종료 뒤 경제 심화, 훈련 품질, 도감/프리셋, 출시 후보 회귀를 진행합니다. 이 번호는 Notion의 공식 Phase가 아닙니다.
