# 게임 개요

## 한 문장 설명

플레이어가 자동 공격을 활용해 몰려오는 적을 쓰러뜨리고, 경험치를 모아 빌드를 성장시키며 제한 시간 동안 생존하는 탑다운 액션 게임입니다.

## 기본 플레이 흐름

```text
이동 → 적 회피 → 자동 공격 → 적 처치 → 경험치 획득
  ↑                                             ↓
게임오버 또는 제한 시간 완료 ← 난이도 상승 ← 레벨업 선택
```

## 첫 버전의 원칙

- 조작은 이동에 집중합니다.
- 공격은 자동으로 수행됩니다.
- 임시 도형으로 시스템을 먼저 검증합니다.
- 기능 추가보다 기능 교체 가능성을 먼저 검증합니다.
