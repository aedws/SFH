# 게임 개요

## 한 문장 설명

플레이어가 자동 공격을 활용해 몰려오는 적을 쓰러뜨리고, 경험치를 모아 빌드를 성장시키며 전리품을 가지고 탈출하는 탑다운 액션 게임입니다.

## 기본 플레이 흐름

```text
작전 규모 선택 → 랜덤 맵 진입 → 이동·자동 공격 → 성장
      ↑                                      ↓
 새 작전 선택 ← 결과 화면 ← 탈출 성공 또는 체력 0
```

## 첫 버전의 원칙

- 조작은 이동에 집중합니다.
- 공격은 자동으로 수행됩니다.
- 임시 도형으로 시스템을 먼저 검증합니다.
- 기능 추가보다 기능 교체 가능성을 먼저 검증합니다.

## 익스트랙션 방향

진입 전에 소형, 중형, 대형 작전 규모를 선택합니다. 큰 작전은 더 많은 진입 비용이 필요하지만 생성 가능한 방 수가 늘어나며, 이후 더 많은 전리품과 위험을 배치하는 기반으로 사용합니다.

현재는 작전 규모 선택, 방해물이 있는 랜덤 맵, `F` 상호작용 탈출과 성공 결과까지 구현했습니다. 실제 지갑 차감과 전리품 보존은 다음 단계에서 연결합니다.
