# 랜덤 맵 생성

**현행 9/9:** [B 복합 구역·A 불규칙 공간·C 1~10 위험 단계](extraction-district.md#compound-20260909). 모든 방에 도로가 직접 붙고 주변을 우회하는 이전 도시형 정책을 대체했습니다. 실제 바닥 셀을 방·스폰·보상·시야·미니맵의 기준으로 사용합니다.

## 바닥 청크 렌더링 · 2026-09-08

`DungeonFloorLayer`가 생성된 바닥 셀을 **셀당1픽셀·기본128×128셀 청크 텍스처**로 그립니다. 9/7의 TileMapLayer 방식에서 발생하던 첫 화면의 대량 타일 갱신·업로드를 제거했습니다. 음수 좌표·다른 셀 크기·재생성·빈 영역 투명도를 지원하며 충돌/내비게이션은 생성하지 않습니다. 벽/기둥 표현, 병합 충돌과 AStar·미니맵·안개용 맵 데이터 계약은 유지합니다. [경계와 검증](../architecture/module-audit.md#first-frame-floor) · [첫 렌더 계측](../performance/minimum-requirements.md#first-frame-20260908).

## 목적

규모는 시설 수·외곽 크기를, 위험 1~10단계는 적/보상 배수와 다각형 시설 비율을 정합니다. 같은 규모에서 난이도를 올린다고 시설 수까지 증가하지는 않습니다. 실제 투입 비용은 작전 계약·결제 서비스가 차감하며, 맵 생성기는 결제나 환불을 직접 처리하지 않습니다.

| 등급 | 임시 진입 비용 | 생성 방 수 | 방 크기 범위 |
|---|---:|---:|---:|
| 소형 | 100 | 21 | 42×25~54×34 셀 |
| 중형 | 300 | 35 | 46×28~60×38 셀 |
| 대형 | 700 | 52 | 50×30~68×42 셀 |

설정 파일은 `game/features/map_generation/configs/`에 있습니다. 현행 지역 정책은 기존 최소~최대(18~24/30~40/45~60)의 중간값을 내림해 골격 크기를 고정합니다. 각 `.tres` 범위를 바꾸면 골격도 달라집니다. [필수 피스와 기획 설계실](extraction-district.md#regional-map).

기본 셀은 32px이며 위 크기는 시설의 **사각 검색 경계**입니다. 작은 소형 경계는 1344×800px이지만 L/T/U·중정·다각형에서 실제 바닥 면적은 줄어듭니다. 기본 PC 화면은 1280×800(16:10)입니다. 실제 바닥 면적·통행 폭의 체감 수락은 별도입니다.

각 등급 Resource는 맵 크기와 목표 플레이 시간을 가집니다. 기존 탈출 신호 시각 값은 현행 구역의 즉시 개방 정책보다 우선하지 않습니다. 자세한 값은 [작전 선택과 탈출](raid-setup-extraction.md)에서 확인합니다.

## 생성 과정

현행은 [익스트랙션 구역](extraction-district.md)입니다. 시설 수·크기 Resource와 기존 바닥 청크 렌더를 유지하고 연결 구조를 바꿉니다.

1. `RegionalDistrictPlan`이 규모·지역 필수 피스·시드로 건물 구획을 정합니다.
2. `CompoundDistrictLayout`이 최대 2×2 구획을 묶고 내부 도로와 전방위 서비스 마당을 제거합니다.
3. `CompoundSpaceShape`가 A 불규칙 바닥을 만들고 계약의 C 비율에 따라 셀 다각형으로 변형합니다.
4. 대표 외부 입구·시설 사이 5셀 연결로·다른 접근로를 만들며, 대각 연결은 다른 시설 중심 대신 건물 사이 간격을 경유합니다. 시작·두 탈출 시설의 외부 접근은 보존합니다.
5. 도로 입구에서 연결 그래프의 최소 깊이로 시설 위험·자원 배치 가중치를 보정합니다. 잠긴 지름길이나 심층 진입 정책을 구현한 것은 아닙니다.
6. 실제 바닥과 통행 축을 보호하며 실내 장애물·병합 충돌·AStar를 구성합니다.
7. 시야·스폰·보상·미니맵은 실제 바닥 마스크와 공개 스냅샷을 사용합니다. 빈 중정/잘린 모서리를 방으로 오인하지 않습니다.

`compound_layout_enabled=false`는 이전 도시형 비교이며 `district_layout_enabled=false`는 더 오래된 나뭇가지형 폴백입니다. 같은 시드·지역·규모·시설 데이터·맵 정책/위험 단계에서 같은 지형을 재현합니다. `ExtractionDistrictLayout`의 폭/여백 설정을 현행 B 구역 연결 정책과 혼동하지 마세요.

## 등급 변경

`game/core/feature_manifest.tres`를 열고 `Map Size`를 변경합니다.

- `small`: 소형
- `medium`: 중형
- `large`: 대형

`Map Seed`가 `0`이면 실행할 때마다 새 맵을 생성합니다. 0이 아닌 같은 숫자를 입력하면 같은 등급과 설정에서 같은 맵을 재현할 수 있습니다.

## 게임과의 연결

- 플레이어는 첫 번째 방 중앙에서 시작합니다.
- 적은 플레이어와 충분히 떨어진 방의 바닥 셀에 생성됩니다.
- 적은 생성된 A* 그리드로 복도와 방을 따라 플레이어를 추적합니다.
- 투사체, 플레이어, 적은 생성된 벽과 방해물에 충돌합니다.
- 초록 원은 시작 지점이며 주황 원은 별도 탈출 모듈이 표시합니다.
- 우측 상단 [전술 미니맵](minimap.md)은 생성된 전체 지형과 현재 위치·탈출 위치를 표시하고, M 확장 시 시작·클리어 정비 시설의 안전 단말 후보를 표시합니다.
- [전장의 안개](fog-of-war.md)는 공개 계약으로 받은 현재 공간과 전체 공간 경계를 사용합니다.

## 방해물

`FeatureManifest.map_obstacles_enabled`로 방해물만 따로 켜거나 끌 수 있습니다. 밀도는 각 등급 Resource의 `Obstacle Density`에서 조절합니다.

- 시작 방에는 생성하지 않습니다.
- 탈출 방에는 생성하지 않습니다.
- 각 방의 중앙 가로·세로 통로는 비워 둡니다.
- 8~18셀 길이의 칸막이는 2셀 출입구를 남겨 실제 실내 구획처럼 배치합니다.
- 3×2~5×3 설비 블록은 기계실·창고 내부 구조물처럼 넓은 면적을 차지합니다.
- 2~3개의 원형 기둥은 일정 간격의 지지 구조로 묶어서 배치합니다.
- 서로 무작위로 흩뿌리는 대신 방마다 벽·기둥 패턴을 선택합니다.
- A* 경로가 끊기면 해당 시드에서는 방해물을 제거하고 경로를 다시 만듭니다.

파밍 모듈에는 위치뿐 아니라 벽 안쪽 방향과 `wall_safe`, `material_locker`, `recovery_terminal` 배치 힌트를 제공합니다. 실제 외형·상호작용 문구·크레딧 수치는 [크레딧 파밍과 회수](credit-loot.md)에서 관리합니다.

## 기능 비활성화

`FeatureManifest.map_generation_enabled`를 끄면 맵 Scene을 불러오지 않습니다. 플레이어는 원점에서 시작하고 적 생성기는 기존 원형 거리 스폰을 사용합니다.

맵 HUD도 함께 숨겨지며 적은 직선 추적으로 돌아갑니다. 자동 테스트가 이 비활성화 구성을 별도로 조립해 확인합니다.

## 모듈 경계

- 맵 내부: 방 배치, 복도, 벽, 길찾기 그리드, 등급 Resource
- 조립부: 맵 Scene 선택 로딩, 시작 위치 전달, HUD Signal 연결
- 소비자: 적 생성기는 스폰 위치, 적은 월드 경로, 미니맵은 지형 스냅샷, 안개는 가시성 영역만 요청

다른 기능은 `MapTierConfig`, 방 배열, A* 그리드를 직접 참조하지 않습니다. 대체 맵 구현에 필요한 공개 계약과 점검 결과는 [모듈화 점검 기록](../architecture/module-audit.md)에 정리되어 있습니다.

## 구현 범위와 잔여

- **구현:** 작전 계약의 재화 차감·원복, 시설 전리품/위험도, 실제 포털과 선택 금고 봉쇄. 각각 계약·파밍·교전 모듈이 소유하며 생성기가 직접 처리하지 않습니다.
- **미구현/별도 판단:** 비밀방, 잠긴 지름길 해제, 심층 진입 정책, 발견 구역의 작전 간 저장.
- **사람 수락 잔여:** 제한 입구 발견·후퇴 선택·다각형 모서리·기본 장비 10분 회수/탈출. [내일 검사 순서](../design/current-milestone-workline.md#next-20260910).
