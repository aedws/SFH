# 로비 장비 보존과 스킬 투자

## 현재 규칙 · 2026-09-03 사용자 결정

**로비에서 아이템 세팅을 마치고 작전에 들어갑니다.** 작전 진입 화면의 MAIN/SUB 무기 선택과 임시 무기 교체는 폐기했습니다. [로비 단말 사용법](hub-economy.md#hub-preparation)을 먼저 읽으세요.

1. I/U/E에서 무기·방어구·모듈·파츠를 장착합니다. I 임시 편집은 나갈 때 저장합니다.
2. 출격 준비 단말에서 요원·스킬·소모품을 설정합니다.
3. 동쪽 작전 게이트 F → 지역·작전 → **세팅 확인** → 검토·투입.
4. 실제 장착 상태를 복사해 전투에 사용합니다. 이미 장착된 무기는 새로 구매하지 않습니다.

무기 슬롯의 허용 태그는 그대로입니다. 기본 메인은 소총, 보조는 권총 규칙이며, 다른 무기군을 허용하려면 슬롯 Resource를 확장합니다.

## 스킬 투자와 제한

| 상태 | 의미 | 결과 |
|---|---|---|
| 소유 | 기본 스킬 | 추가 비용 없이 사용 |
| 미해금 | 요구 지역·영구 해금 없음 | 출격 거절, 무차감 |
| 이번 런 구매 | 해금됐지만 이번 작전에 비용 필요 | 계약 총액에 한 번 합산 |
| 구매 완료 | 현재 런 비용 확정 | 종료 시 런 구매 상태 해제 |
| 무기 태그 불일치 | 활성 무기가 스킬 요구 태그를 충족하지 않음 | 출격은 가능, 해당 스킬만 비활성 |

아크 질주 60 C는 현행 임시 스킬 투자값입니다. 기존 펄스 소총 80 C 열은 레거시 데이터로 유지하지만 **기본 게임의 출격 무기 비용으로 소비하지 않습니다.** 품질별 상점 실물 지급은 P7-01B의 별도 미완료 작업입니다.

## 데이터·모듈 계약

- 기존 Weapon/Skill Sheet의 가격·소유·해금 열 및 확정 CSV·Web payload는 유지합니다. 새 목록은 필요하지 않아 Sheet를 확장하지 않았습니다.
- 게임 조립 때 `LoadoutInvestmentService.preserve_equipped_weapons()`를 적용합니다. 무기 선택 API는 거부하고 `weapon_paths`는 비우며, 스킬만 추가 투자 문맥으로 전달합니다. 실시간/확정 CSV 전환 후에도 정책은 유지됩니다.
- `equipment_override_policy=preserve_hub_equipment`로 명시합니다. Game의 카탈로그 무기 교체 루프 자체도 제거했습니다.
- 실제 장비·가방의 출격 원본은 제공자의 `export_runtime_state()`입니다. 강화·모듈·파츠·빈 슬롯과 가방 배치를 보존합니다.
- [사전검증](operation-launch-preflight.md)은 장비·가방·해금·비용을 검증하고 계약은 한 번만 차감합니다. 열린 편집창이 있으면 직접 시작 호출도 차단합니다.
- 정상 귀환은 준비 상태를 보존하되 **사망/실패의 장착품 소실은 기존 정산 규칙**을 따릅니다.

서비스 자체의 레거시 카탈로그 모드는 독립 계약 테스트와 데이터 호환을 위해 남습니다. 기본 Game에는 항상 장착 보존 모드를 주입하며, 로비 UI를 끄더라도 무기 교체는 되살아나지 않습니다.

## 검증

`loadout_investment_contract_test.gd`는 미해금 스킬 무차감, 스킬 추가 60 C의 1회 청구, 실제 소총·모듈·파츠 보존, 전격 스킬 발동과 보조 무기 전환 후 비활성을 확인합니다.

`hub_preparation_contract_test.gd`는 F/클릭/I 편집 확인/ESC/Q/출격 버튼으로 로비→전투→복귀를 확인합니다. 장비 값 사본·가방 배치, 슬롯 규칙 확장 후 비카탈로그 대검, 선택 제거, 4화면 크기를 검사합니다. 작전 81조합과 12세팅 회귀도 유지합니다.
