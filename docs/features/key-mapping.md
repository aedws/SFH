# K 키 설정과 영구 바인딩

거점과 작전에서 `K`를 누르면 키 설정 화면이 열립니다. 이동·대시·기본 공격·상호작용·무기 교체·스킬 1~9·I/U/E 메뉴와 K 자체까지 총 21개 Action을 키보드 또는 마우스 버튼으로 바꿀 수 있습니다. 변경값은 즉시 `user://sfh_key_mapping.json`에 저장되어 재실행 뒤에도 유지됩니다.

## 사용법

1. `K`로 키 설정을 엽니다.
2. 바꾸려는 항목 오른쪽의 현재 키 버튼을 누릅니다.
3. 원하는 키보드 키 또는 마우스 버튼을 누릅니다.
4. 이미 다른 항목에서 쓰는 키라면 두 항목의 키가 교환됩니다.
5. `전체 기본값 복원`으로 모든 Action을 초기 상태로 되돌립니다.

`ESC`는 입력 대기를 취소하고 화면을 닫는 비상 키라서 재지정할 수 없습니다. K 자체를 다른 키로 바꾸면 이후에는 새 키로 설정 화면을 엽니다. 화면의 조작 안내도 현재 저장된 키 이름으로 즉시 갱신됩니다.

## 모듈 구조

```text
KeyMappingCatalog Resource
  └─ Action ID · 표시명 · 기획 분류 21개

KeyMappingService
  ├─ InputMap 기본값 캡처
  ├─ 키보드·마우스 입력 정규화
  ├─ 중복 키 교환
  ├─ JSON 저장·복원
  └─ bindings_changed Signal

KeyMappingPanel
  ├─ K/ESC 입력과 입력 대기 UI
  └─ Service 공개 계약만 호출
```

플레이어 이동은 더 이상 `WASD` 물리 키를 직접 읽지 않습니다. `move_up/down/left/right`와 `dash` Action만 읽으므로 저장된 설정이 실제 이동과 대시에 그대로 적용됩니다. I/U/E 같은 기존 화면도 각각의 Action을 사용해 같은 저장 계약을 공유합니다.

## 기본값

| 분류 | Action | 기본값 |
| --- | --- | --- |
| 이동 | 위/아래/왼쪽/오른쪽 | `W` / `S` / `A` / `D` |
| 이동 | 대시 | `Space` |
| 전투 | 기본 공격 / 상호작용 / 무기 교체 | `마우스 1` / `F` / `Q` |
| 스킬 | 전투 스킬 1~9 | 숫자 `1`~`9` |
| 메뉴 | 가방 / 장비 / 모듈·파츠 / 키 설정 | `I` / `U` / `E` / `K` |

## 교체·비활성화

- `FeatureManifest.key_mapping_enabled=false`이면 서비스와 K 화면만 설치하지 않습니다.
- Action 목록과 기획자 표시 순서는 `default_key_mapping.tres`에서 바꿉니다.
- 저장 방식을 클라우드 프로필로 교체하려면 `KeyMappingService`의 공개 계약을 구현하는 제공자로 바꿉니다.
- 자동 검증은 21개 Action, ESC 예약, 중복 교환, JSON 저장, 패널 행 수와 실제 K/ESC 입력을 검사합니다.
