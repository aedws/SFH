# 모바일 키패드와 HUD 표시 설정

브라우저 플레이는 터치 기기를 감지하면 화면 키패드를 자동으로 표시합니다. 키패드는 게임 규칙을 직접 호출하지 않고 기존 `InputMap Action`만 누르고 떼므로 키보드·마우스와 같은 이동·공격·스킬·상호작용 경로를 사용합니다.

## 플레이어가 바꿀 수 있는 항목

`K` 입력 설정의 `HUD·모바일` 탭에서 다음 항목을 순환 선택합니다.

| 설정 | 값 | 기본값 |
|---|---|---|
| 플레이어 상태 HUD 위치 | 좌하단·하단 중앙·우하단 | 좌하단 |
| HUD 키 표시 형식 | 간결·대괄호·숨김 | 간결 |
| 모바일 키패드 | 터치 자동·항상 표시·항상 숨김 | 터치 자동 |

플레이어 상태 HUD에는 HP, XP, 레벨, 처치 수, 휴대 크레딧이 묶입니다. 모바일 키패드가 보이는 좌하단에서는 상태 HUD를 위로 올려 터치 영역과 겹치지 않게 합니다.

## 터치 표면

- 왼쪽: 상·하·좌·우 이동
- 오른쪽: 기본 공격, 대시, 스킬 1·2·3, 상호작용
- 상단: 무기 교체, 전술 지도, 가방, 장비, 모듈·파츠, 설정

모달·작전 설정·결과 화면에서는 키패드를 숨기고, 닫은 뒤 원래 터치 컨텍스트를 복구합니다. 각 버튼은 의미 툴팁을 가지며 동시 터치를 허용합니다.

## 모듈 경계

| 모듈 | 책임 | 알지 못하는 것 |
|---|---|---|
| `PresentationSettingsService` | JSON 저장, HUD 위치·키 형식·모바일 모드 | 전투 규칙, 실제 UI 노드 |
| `MobileControlPad` | 터치를 semantic Action으로 변환 | 키보드 물리 키, 피해·이동 계산 |
| `CombatHudPresenter` | 설정 스냅샷을 배치·표기에 반영 | 설정 저장, 터치 입력 |
| `KeyMappingPanel` | 세 설정의 선택 UI | 저장 형식, 전투 처리 |

`FeatureManifest`에서 `mobile_controls_enabled`를 끄면 키보드·마우스 플레이는 유지됩니다. 모바일 패드는 `presentation_settings`에만 의존하며, 표시 설정 자체도 독립적으로 끌 수 있습니다.

## 검증

계약 테스트는 16개 Action, 동시 터치 준비, 입력 press/release, 설정 저장·복구와 모듈 제거를 확인합니다. 실제 플레이 E2E는 K에서 HUD 위치·키 형식·모바일 모드를 바꾸고, 패드의 오른쪽 이동을 눌러 월드 좌표가 변한 뒤 기본값으로 복원되는지 판정합니다.

## 검색 별칭

모바일 조작, 터치 키패드, 가상 패드, HUD 이동, 좌하단 상태 UI, 키 포맷, 키 숨김, 브라우저 모바일
