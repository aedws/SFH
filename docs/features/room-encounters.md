# 시설 교전과 선택형 금고

[익스트랙션 구역](extraction-district.md)의 현행 기본값입니다. 일반 방 진입마다 봉쇄하던 이전 기본 규칙을 교체했습니다.

| 상황 | 적·문·보상 |
|---|---|
| 시작/탈출 시설 | 일반 시설 적 생성 대상에서 제외 |
| 일반 시설 안쪽 48px 진입 | 최소 무리 생성. 문은 열려 있어 후퇴 가능 |
| 다른 시설로 후퇴 | 이미 생성한 적이 남아 추적. 재입장 중복 생성 없음 |
| 일반 시설 무리 처치 | 확보 처리와 현장 전리품. 금고 전용 크레딧 상자는 생성하지 않음 |
| 금고 입장 | 아직 봉쇄하지 않음. 중앙 단말에서 F 선택 |
| 금고 단말 110px 내 F | 수량/예산 검증 → 적 생성 → 모든 출입구 봉쇄 |
| 금고 무리 전멸 | 문 개방 → 면적·난수 보정 크레딧 박스 1~5개 → F 회수 |

## 수량과 안전

| 작전 | 기본 최소~최대 무리 | 총 생성 한계 |
|---|---:|---:|
| 소형 | 12~18 | 120 |
| 중형 | 18~26 | 220 |
| 대형 | 24~34 | 360 |

시설의 중심 거리와 `risk_bonus`가 수량을 보정하지만 동시 적 상한과 총 예산은 넘지 않습니다. 일반 교전은 미완료 금고 최소 무리를 예약하고 남은 예산만 사용합니다. 남은 예산/개체 공간이 최소치보다 작으면 약한 부분 무리를 만들지 않습니다. 따라서 모든 시설에서 반드시 전투가 열린다는 뜻은 아닙니다.

최대 교전 방 수는 이전 봉쇄 정책의 설정입니다. 현재 일반 교전은 총 적 예산과 방문 상태를 사용하고 금고는 예약한 최소 무리를 보장합니다. 보스·추격자는 일반 무리 전멸 판정과 독립입니다.

## 진입 스폰 안전 {#spawn-safety}

핵앤슬래시 최소 무리 수는 줄이지 않습니다. 대신 방 진입 좌표에서 **최소 288px 밖**의 걸을 수 있는 셀만 후보로 사용하고, 생성 직후 **1.6초 동안 접촉 피해를 끄며** 적을 반투명하게 표시합니다. 유예가 끝나면 각 적이 원래 갖고 있던 `damage_enabled` 상태를 복원합니다.

두 수치는 `default_room_spawn_safety.tres`의 `RoomEncounterSpawnSafetyPolicy`가 단독 소유합니다. 맵은 배제 좌표·거리만 받아 위치를 반환하고, 적 생성기·AI·체력·방당 수량 정책은 바뀌지 않습니다. 따라서 이후 경고 시간이나 안전 거리를 조정해도 방 수량과 전투 로직을 수정하지 않습니다.


## 보상과 탈출

금고 상자의 수·크레딧 범위는 `default_room_encounters.tres`를 유지합니다. 일반 적 드랍과 시설의 현장 전리품은 기존 전리품 생명 주기를 사용합니다. Facility의 `cache_weight`는 현장 자원 배치 가중치이며 금고 상자당 지급 배율이 아닙니다.

모든 방을 정리해야 탈출하는 규칙은 없습니다. 두 출구는 처음부터 현장 방어를 시작할 수 있습니다. 금고 확보 알림은 보스 경고의 잔여 메시지에 가려지지 않도록 우선순위를 분리했습니다.

## 모듈 구조

- `DistrictEncounterSystem`: 일반 무리·방문·생존 상태와 명시적 금고 요청.
- `RoomEncounterSystem`: 금고 봉쇄·전멸·1~5상자·신호. 기존 기능 비활성 폴백 유지.
- 맵: 복사한 `get_room_encounter_snapshot()`과 안전 배치 위치 제공.
- 스포너: `spawn_enemy_at()`, 총 예산, 동시 개체 스냅샷. 시설 시스템이 AI 내부를 수정하지 않음.
- 안전 정책: 288px 배제, 1.6초 접촉 유예. 일반 무리별로 후퇴 이후에도 유예 복원.
- 워프: 안전 단말/근접 위협/봉쇄 조건을 별도 `RoomWarpSystem`이 검증.

`room_encounters_enabled=false`면 시설 무리·봉쇄·방 보상을 설치하지 않고 기존 전역 생성 폴백을 사용합니다. `district_layout_enabled=false`면 기존 방 교전 정책으로 돌아갑니다.

## 검증

[실제 입력·전멸·보상 E2E](../quality/e2e-play-session.md#extraction-district): 세 규모 하드 최소 무리, 후퇴 시 적 유지, 재진입 중복 없음, 단말 외 봉쇄 거부, 모든 금고 문 폐쇄/해제, 1~5상자와 F 회수, 예산·기능 비활성 폴백을 구분합니다.
