# 투입액 회수 엘리트 추격자

작전에서 휴대 크레딧이 해당 작전의 실제 투입 비용에 도달하면 `위협 경보`와 함께 엘리트 추격자 1~2마리가 랜덤 위치에 한 번 생성됩니다. 투입 비용을 회수한 순간부터 안전한 파밍 동선을 흔드는 런 단위 압박 장치입니다.

## 임시 수치

| 항목 | 현재값 | 교체 지점 |
|---|---:|---|
| 발생 임계 | 투입 비용 × 1.0 | `carried_credit_threshold_multiplier` |
| 생성 수 | 1~2 | 최소·최대 엘리트 수 |
| 생성 거리 | 420~680px | 최소·최대 거리 |
| 이동 속도 | 플레이어 현재 속도 × 1.08 | 속도 배율 |
| 접촉 공격력 | 현재 무기 피해 기준 × 1.12 | 공격 배율 |
| 체력·방어력 | 24·10 | 엘리트 프로필 |
| 자동 타게팅 등급 | 4 | 우선 등급 |

현재 값은 기획 데이터 부재 상태의 교체 가능한 임시값입니다. 신규 적 목록이 아니라 단일 정책 프로필이므로 Google Sheet는 확장하지 않았습니다. 엘리트 종류·고유 드랍·복수 프로필이 확정되면 기존 1행 변수·2행 설명·3행 데이터 규칙으로 별도 표를 추가합니다.

## 방 전투와 분리되는 규칙

- 엘리트는 `room_encounter_id`를 갖지 않습니다.
- 일반 방의 최소 스폰량·증원 한계·전체 스폰 예산을 소비하지 않습니다.
- 방 문 충돌 레이어를 무시하고 내비게이션 방 경계 대신 플레이어를 직접 무한 추적합니다.
- 엘리트가 살아 있어도 방의 일반 적을 모두 처치하면 문은 열리고 보상이 생성됩니다.
- 스마트 자동 타게팅 목록에는 포함되며 높은 등급 대상으로 판정할 수 있습니다.

## 모듈 경계

`ElitePursuitService`는 `CreditLedger` 신호를 관찰해 임계값을 판정하고 `EnemySpawner`의 엘리트 생성 명령만 호출합니다. 엘리트 프로필은 Resource, 시각·이동 계약은 Enemy, 일반 예산 분리는 Spawner가 소유합니다. `elite_pursuit_enabled`를 끄면 기존 방 전투·크레딧·적 생성은 그대로 동작합니다.

## 플레이어 인식 E2E

실제 작전에서 방을 봉쇄한 상태로 휴대 크레딧을 투입액까지 올린 뒤 다음을 확인합니다.

1. 화면에 회수액과 전역 엘리트 추격 경보가 보입니다.
2. 랜덤 1~2마리가 일반 스폰 예산을 쓰지 않고 생성됩니다.
3. 플레이어와의 거리가 실제 물리 프레임에서 줄어듭니다.
4. 방 적 수와 잠긴 문 수는 발생 전후 같습니다.
5. 방 일반 적을 모두 처치하면 엘리트가 남아 있어도 문이 열립니다.
