# 투입액 50% 회수 추격 보스

**9/23 병존 규칙:** 이 문서의 회수액50% 추격 보스는 그대로 유지합니다. 작전20분에 등장하는 Hunter는 별도 시간 압박 모듈이 소유하므로 두 보스가 동시에 존재할 수 있습니다. 각각 성공적으로 생성한 뒤에는 처치해도 재생성하지 않습니다. [20분 오염·30분 붕괴](extraction-defense-results.md#pressure-20260923).

작전 진입 후 **실제로 지불한 진입 비용의 50% 이상을 휴대 크레딧으로 회수하는 순간**, `위협 경보`와 함께 추격 보스 1기가 랜덤 위치에 한 번 등장합니다. 기존 100% 회수·엘리트 1~2기 정책을 대체합니다. 요원·로드아웃 등을 포함해 확정된 작전 계약의 최종 `entry_cost`가 기준이며, 로비 보유 재화는 합산하지 않습니다.

정수 크레딧이므로 소수점은 올립니다. 100 C 진입은 50 C, 101 C는 51 C입니다. 무료 작전은 기존 최소 임계 정책을 유지해 첫 1 C 회수 시 등장하며, 로비에서나 작전 준비 중에는 생성되지 않습니다. 이후 크레딧을 쓰거나 보스를 처치해도 같은 런에서 재생성하지 않습니다.

## 보스 등장 경고와 외곽 방향 표시

- 보스가 생성되면 상단 중앙에 **3.5초간 `보스 등장` 경고**가 표시됩니다. 추격 보스는 `문을 넘어 추격 중`, 일반 보스는 `교전 주의`로 구분합니다.
- 화면 밖에 있는 보스마다 화면 외곽의 **주황색 화살표**가 해당 방향을 가리킵니다. 카메라 이동·줌·화면 크기 변화에 맞춰 위치를 계산하며, 화면 안으로 들어오면 해당 화살표는 숨깁니다.
- 처치/제거 즉시 해당 표시를 없애고, 마지막 보스가 사라지면 남은 등장 경고도 종료합니다. 방 문 개폐와는 무관합니다.
- I/U/E·일시정지·결과 화면에서는 숨기고, 일시정지 중 경고 시간이 소모되지 않습니다. 작전 복귀 시 HUD와 신호 연결을 제거합니다.
- 화면 전체를 깜빡이거나 덮지 않습니다. 배너는 최대 320×34px, 화살표는 24px 외곽 여백 안쪽에 배치하며 마우스/터치 입력을 가로채지 않습니다. 이모지 대신 직접 그린 도형과 기존 한글 폰트를 사용합니다.

`boss_warning`은 추격 생성과 독립적인 표현 모듈입니다. `BossThreatTracker`는 Spawner의 `enemy_spawned/get_active_targets`, Enemy의 `get_combat_identity/defeated`만 구독합니다. `BossEdgeProjection`은 좌표 계산, `BossWarningHud`는 표시·수명, `BossWarningStyle`은 시간·여백·크기·색상을 담당합니다. Manifest의 `boss_warning_enabled`를 끄거나 적 생성을 끄면 HUD는 설치되지 않으며 보스 전투 규칙은 바뀌지 않습니다. 새로운 게임 목록이 아니므로 Sheet 확장·CSV 변경은 없습니다.

## 정책과 현재 수치

| 항목 | 현재값 | 교체 지점 |
|---|---:|---|
| 발생 임계 | 투입 비용 × 0.5, 올림·최소 1 C | `carried_credit_threshold_multiplier` |
| 생성 수 | 1 | 최소·최대 추격자 수 |
| 전투 역할 | 보스 | `spawn_as_boss` |
| 생성 실패 재시도 | 1초 | `spawn_retry_seconds` |
| 생성 거리 | 420~680px | 최소·최대 거리 |
| 이동 속도 | 플레이어 현재 속도 × 1.08 | 속도 배율 |
| 접촉 공격력 | 현재 무기 피해 기준 × 1.12 | 공격 배율 |
| 체력·방어력 | 24·10 | 추격자 프로필 |
| 자동 타게팅 등급 | 5 | 우선 등급 |

**50% 발생과 방·문 독립 추격은 사용자 지정 규칙**입니다. 나머지 수치는 교체 가능한 테스트 기본값이며 출격 시 정책 복사본을 고정합니다. 신규 적 목록이 아니라 기존 단일 정책 프로필 변경이므로 Google Sheet는 확장하지 않았습니다. 종류·고유 드랍·복수 프로필이 필요해지면 기존 1행 변수·2행 설명·3행 데이터 규칙으로 확장합니다.

## 방 전투와 분리되는 규칙

- 추격 보스의 `room_encounter_id`는 빈 값이며 방 전투 소속이 아닙니다.
- 일반 방의 최소 스폰량·증원 한계·전체 스폰 예산을 소비하지 않습니다.
- 방 문 충돌 레이어를 무시하고 내비게이션 방 경계 대신 플레이어를 직접 무한 추적합니다.
- 보스가 살아 있어도 방의 일반 적을 모두 처치하면 문은 열리고 보상이 생성됩니다. 그 뒤 다른 방으로 이동하거나 다시 문이 닫혀도 보스의 이동·접촉 피해는 계속됩니다.
- 스마트 자동 타게팅 목록에는 포함되며 높은 등급 대상으로 판정할 수 있습니다.
- 실제 처치 시 보스 격파로 한 번 집계합니다. 별도의 작전 계약 보스 확정 생성은 이 추격자와 독립적입니다.
- 현재 문과 월드 장애물이 같은 충돌 레이어를 쓰므로 추격자는 장애물도 통과합니다. 추적 해제 거리·방 경계 리셋은 없지만 일반 일시정지·작전 종료와 보스 사망은 그대로 적용됩니다.

## 모듈 경계

기존 모듈 ID와 경로는 호환성을 위해 유지합니다. `ElitePursuitService`는 `CreditLedger` 신호와 `EnemySpawner.spawn_elite_pursuer_at`만 사용합니다. 프로필은 Resource, 이동·피해는 Enemy, 보스 역할 등록과 일반 예산 분리는 Spawner, 격파 집계는 `RunCombatMetrics`가 소유합니다. `elite_pursuit_enabled`를 끄면 기존 방 전투·크레딧·적 생성은 그대로 동작합니다.

생성 실패 시 1회 트리거를 소비하지 않고 제한 주기로 재시도합니다. 생성에 성공한 뒤에는 프레임 검사를 끄며, 누적 생성 수와 현재 생존 수를 분리합니다. 재구성할 때 이전 크레딧 신호 구독을 해제합니다.

## 플레이어 인식 E2E

실제 작전에서 방을 봉쇄한 상태로 휴대 크레딧을 투입액의 절반까지 올린 뒤 다음을 확인합니다.

1. 화면에 회수액과 추격 보스·문 무관 추격 경보가 보입니다.
2. 50% 이전에는 없고, 임계 도달 시 보스 1기가 일반 스폰 예산을 쓰지 않고 생성됩니다.
3. 플레이어와의 거리가 실제 물리 프레임에서 줄어듭니다.
4. 방 적 수와 잠긴 문 수는 발생 전후 같습니다.
5. 방 일반 적을 모두 처치하면 보스가 남아 있어도 문이 열립니다.
6. 실제 `RoomDoorBarrier` 충돌체를 통과한 접촉 피해를 확인하고, 문을 열었다 다시 닫은 뒤에도 반복 검증합니다.
7. 101 C·무료 작전 임계, 생성 실패 후 추가 회수 없는 재시도, 보스 처치 1회·추가 회수 후 재생성 금지를 검사합니다.
