# 도면 제작과 랜덤 옵션

정책은 **완제품 직접 드랍보다 도면 반출 후 거점 제작을 주 획득 경로로 사용**하는 것으로 임시 확정했습니다. 성공 정산에서 지역별 확률로 도면을 반입하고, 거점에서 도면 1개·고철·영구 크레딧을 소비해 장비를 만듭니다.

| 도면 | 결과 | 고철 | 크레딧 | 옵션 |
|---|---|---:|---:|---:|
| 돌격소총 | 제작 돌격소총 | 5 | 400 C | 1~2개 |
| 전술 조끼 | 제작 전술 조끼 | 4 | 350 C | 1~2개 |

현재 옵션 풀은 화력, 발사 순환, 생명력, 장갑입니다. 옵션은 가중 무작위로 뽑되 같은 제작품에 동일 옵션이 중복되지 않으며 각 옵션의 최소~최대 범위 안에서 수치를 결정합니다.

제작 결과는 정의 ID, 고유 인스턴스 ID와 옵션 배열로 영구 프로필에 저장합니다. 장비 시스템에 실제 장착하는 연결은 후속 장비 카탈로그 변환 계층에서 처리하며 제작 서비스가 장비 슬롯을 직접 수정하지 않습니다.
