# 도면 제작과 랜덤 옵션

정책은 **완제품 직접 드랍보다 도면 반출 후 거점 제작을 주 획득 경로로 사용**하는 것입니다. P7-03부터 성공 정산으로 반출한 도면은 소비 수량과 별개인 영구 제작 등록으로 전환됩니다. P7-04부터 비용·재료·무작위 범위를 먼저 확인하고, 한 번의 원자적 거래로 실제 옵션과 소켓을 가진 장비를 제작합니다.

| 도면 | 결과 | 고철 | 크레딧 | 옵션 |
|---|---|---:|---:|---:|
| 돌격소총 | 제작 돌격소총 | 2 | 80 C | 1~2개 |
| 전술 조끼 | 제작 전술 조끼 | 2 | 70 C | 1~2개 |
| 원형 자기장 | 제작 원형 자기장 | 3 | 95 C | 1~3개 |

현재 표의 비용·옵션·소켓은 `Recipe` Sheet의 `provisional` 값입니다. P7-04는 이 값을 운영 확정으로 오인하지 않고 교체 가능한 Roll Resource 뒤에 두었습니다. 기획 확정 시 레시피와 옵션 풀만 교체하며 거래·저장 코드는 바꾸지 않습니다.

## P7-03 모듈 경계

- `BlueprintRegistry`: 프로필의 영구 등록 ID만 읽고 쓰며 중복 등록을 멱등 처리합니다.
- `WorkshopRecipeProvider`: `Recipe` CSV를 제작법 ID·도면 ID로 조회합니다. 저장과 UI를 모릅니다.
- `WorkshopUnlockService`: 반출 수량을 검사하고, 존재하는 제작법의 도면만 등록하며 `재제작 가능/도면 반출 필요` 후보를 만듭니다.
- `WorkshopService`: 아래 모듈을 조립하고 공개 후보·견적·제작 명령만 제공합니다. 프로필 저장 구조와 UI Node를 모릅니다.

## P7-04 제작 거래와 Roll {#p7-04}

- `WorkshopRollPolicy`: 옵션 풀, 가중치, 수치 범위, 소켓 상한과 결정 시드를 소유합니다. 같은 레시피·거래 ID·세션 시드는 같은 결과를 만들며 옵션 ID는 중복되지 않습니다.
- `WorkshopCraftTransactionService`: 도면 등록, 비용, 재료, 거래 중복을 먼저 검증하고 크레딧·재료·완제품·거래 ID를 프로필의 단일 명령으로 반영합니다.
- `PersistentProfile.apply_economy_transaction`: 모든 변경의 최종 상태를 메모리에서 검증한 뒤 한 번만 저장합니다. 잔액 부족, 재료 부족, 중복 인스턴스나 저장 실패는 부분 차감 없이 거부됩니다.
- 제작 후보와 툴팁은 제작 전에 `비용/현재 잔액`, `재료 보유/필요`, `옵션 최소~최대`, `소켓 최소~최대`를 보여줍니다.
- 제작된 장비는 실제 옵션 배열과 빈 소켓 배열, Roll 시드·출처 상태를 영구 프로필에 저장하며 재접속 뒤에도 유지됩니다.
- `P5HubProgressionService`: `register_extracted_blueprints / get_workshop_candidates / craft_recipe` 공개 계약만 제공합니다.

거점 제작소 버튼에는 `도면 1/3`처럼 영구 등록 수가 표시되고, 마우스를 올리면 각 제작 후보의 상태·비용·재료·Roll 범위를 확인할 수 있습니다. 제작 결과는 정의 ID, 고유 인스턴스 ID, 실제 옵션과 소켓을 영구 프로필에 저장합니다.

## Google Sheet 확인 · 2026-09-04

`Recipe!A1:M5`의 3개 제작법은 현재 확정 CSV와 같습니다. 새 레시피 목록은 추가하지 않았습니다. 전체 시트 대조 중 `Item!A18:P21`에 Utility 전용 4행이 중복된 것은 발견했지만, Item 생명주기 스키마와 맞지 않아 자동 반영하지 않았습니다. 해당 행은 `Utility` 탭에서만 관리하도록 기획 데이터 정리가 필요합니다.

## 자동 검증

`P7_BLUEPRINT_REGISTRY_OK`는 미등록 표시, 알 수 없는 도면 거부, 반출 1회 등록, 중복 멱등, 재접속 후 제작 후보 유지와 façade 조회를 판정합니다. `P7_WORKSHOP_TRANSACTION_OK`는 견적 무변경, 비용·재료·범위 선공개, 단일 저장 제작, 중복 거래 차단, 실제 옵션·소켓, 재접속, 정책 교체, 공급자 실패 무변경과 영구 저장 실패 메모리 원복을 판정합니다.
