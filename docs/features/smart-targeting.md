# 스마트 자동 타게팅

에임이 없는 SFH의 기본 자동 공격은 단순 최근접 대신 다음 네 값을 합성합니다.

| 기준 | 가중치 | 의미 |
|---|---:|---|
| 거리 | 45% | 가까울수록 높은 점수 |
| 처형 가능성 | 20% | 현재 체력 비율이 낮을수록 높은 점수 |
| 우선 등급 | 20% | 일반 1~정예 5 등급이 높을수록 우선 |
| 밀집도 | 15% | 반경 180px 안의 다른 적이 많을수록 우선 |

이 정책은 현재 기본 확정안입니다. 가중치, 밀집 반경, 기준 밀집 수와 최대 우선 등급은 Resource에 있으며 무기별 정책이나 관통·범위용 정책으로 교체할 수 있습니다. `smart_targeting_enabled`를 끄면 기존 최근접 대상 방식으로 즉시 복귀합니다.

적은 `get_targeting_snapshot()`으로 체력·장갑·우선 등급만 공개합니다. 타게팅 정책은 적의 HealthComponent 경로나 생성기 내부 배열을 읽지 않습니다.

## 성능

대상 선택은 탄환 매 프레임이 아니라 새 발사 묶음이 시작될 때만 수행합니다. 대형 최대 72명 조건을 성능 예산 테스트에 포함했습니다.
