# 작전 선택과 탈출

## 한 판의 시작

프로젝트를 실행하면 [큰 단일 방의 시작 거점](start-hub.md)에 진입합니다. 동쪽 작전 게이트로 이동해 `F`를 눌러야 작전 규모 선택 화면이 열립니다.

| 선택 | 투자 표시 | 방 수 | 목표 시간 | 탈출 신호 개방 |
|---|---:|---:|---:|---:|
| 소형 작전 | 100 | 18~24 | 9분 | 9분 |
| 중형 작전 | 300 | 30~40 | 10분 | 10분 |
| 대형 작전 | 700 | 45~60 | 11분 | 11분 |

규모 카드는 계약을 **선택만** 하고, 우측 아래 `작전 투입`으로 확정해야 영구 크레딧을 실제 차감합니다. 확정 뒤 맵, 플레이어, 탈출 지점, 미니맵, 전투 모듈 순서로 설치합니다. 검사나 조립이 실패하면 비용과 소모품을 자동 반환하고 선택 화면을 유지합니다. 기본 계약 비용을 낼 수 없으면 0 C 파산 방지 계약과 기본 무장을 제공합니다.

자동 테스트는 소형·중형·대형 카드를 각각 눌렀을 때 전투가 즉시 시작되지 않는지, 선택 강조와 계약값이 갱신되는지, 별도 투입 확정 뒤 방 수·플레이어·탈출 지점·미니맵이 설치되는지 확인합니다.

## 작전 브리핑 화면

참조 UI의 정보 계층을 SFH 계약 데이터에 맞춰 다음처럼 재구성했습니다. 장식용 숫자를 새로 만들지 않고 실제 `OperationContractService`, 맵 등급, 적 생성, 페널티와 영구 프로필 스냅샷만 표시합니다.

| 영역 | 표시 정보 | 플레이 판단 |
|---|---|---|
| 왼쪽 브리핑 | 지역·규모·난이도, 전술 경로 프리뷰, 목표 시간, 방·적 범위 | 이번 판의 길이와 교전 밀도 확인 |
| 왼쪽 예상 회수 | 투입 비용, 회수·고등급 배율, 보스 보장 | 투자 대비 기대 보상 확인 |
| 오른쪽 조건 | 지역·난이도·페널티, 상점·제작·소모품 | 계약과 준비 상태 변경 |
| 오른쪽 규모 | 소·중·대형 카드와 현재 선택 강조 | 맵 규모 선택, 즉시 출격하지 않음 |
| 오른쪽 위험 | 적 HP·공격·방어·이동 배율, 선택 페널티 | 실제 난이도 변화 확인 |
| 하단 확정 | 선택 계약·소모품 요약, 실제 투입 비용 버튼 | 모든 조건을 읽은 뒤 명시적으로 출격 |

전술 프리뷰는 외부 이미지가 아니라 교체 가능한 코드 드로잉입니다. 지역은 색상, 규모는 탈출 위험 색, 난이도는 적 접촉점 수로 표현하며 실제 맵 배치의 완전한 스포일러는 제공하지 않습니다.

## 전투 HUD 정보 계층

작전 진입 뒤 상단 HUD는 1040×144px 전술 카드로 압축했습니다. 생존·탈출·레벨·처치·휴대 크레딧을 첫 줄, 체력과 런 경험치를 굵기가 다른 게이지, 장비와 현재 무기를 나란한 두 칸으로 배치합니다. 미니맵은 우측 상단의 기존 전체 지도 위치를 유지하고 상단 HUD와 수직으로 분리됩니다. 하단 스킬·에너지·대시 UI 계약은 그대로 유지합니다.

## F 상호작용

프로젝트 입력 액션 `interact`에 물리 키 `F`를 할당했습니다. 앞으로 문, 상자, NPC 같은 기능도 하드코딩된 키 대신 이 액션을 공통으로 사용합니다.

현재 구현된 상호작용은 탈출입니다.

1. 시작 방에서 가장 먼 방의 탈출 지점을 확인합니다.
2. 신호 개방 전에는 마커가 회색이며 F 탈출 요청을 거부합니다.
3. HUD에서 목표 시간과 탈출 신호까지 남은 시간을 확인합니다.
4. 신호 개방 후 마커가 주황색으로 바뀌고 범위 안에 `F · 작전 지역에서 탈출`이 표시됩니다.
5. `F`를 누르면 방어 카운트다운이 시작됩니다. 범위 이탈 시 남은 시간이 일시정지되고 재진입 후 이어집니다.
6. 방어 성공 Signal 뒤 생존 시간, 작전 규모, 처치·반출 가치·3종 순위를 결과 화면에 표시합니다.
7. Enter 또는 버튼으로 전투 세션을 정리하고 시작 거점으로 복귀합니다.

## 모듈 경계

탈출 기능은 `game/features/extraction/`에 독립 Scene으로 있습니다.

- 맵 모듈은 탈출 가능한 월드 위치만 제공합니다.
- 탈출 모듈은 범위 판정, F 입력, 마커 표현을 담당합니다.
- `Game`은 등급 Resource의 개방 시각만 읽어 `set_locked()` 공개 계약으로 상태를 전달합니다.
- `Game`은 `extraction_completed` Signal을 받아 작전 결과 화면을 엽니다.
- 탈출 모듈은 맵의 방 배열이나 A* 객체를 참조하지 않습니다.
- `OperationSetupPresenter`는 계산을 하지 않고 기존 계약·프로필 스냅샷을 브리핑 화면에 투영합니다.
- `CombatHudPresenter`는 기존 HUD Label과 ProgressBar를 재사용해 배치·스타일만 교체합니다.
- 두 Presenter를 제거해도 작전 계약·비용·맵 생성·전투 계산은 유지됩니다.

## 기능 토글

- `start_hub_enabled`: 이동 가능한 큰 시작 방과 작전 게이트 활성화
- `run_setup_enabled`: 게이트에서 등급 선택 화면 표시
- `extraction_enabled`: 주황색 탈출 지점과 F 탈출 활성화
- `map_obstacles_enabled`: 맵 내부 충돌 방해물 활성화

세 기능은 `game/core/feature_manifest.tres`에서 켜고 끕니다. `run_setup`, `extraction`, `map_obstacles`는 모두 `map_generation`에 의존하므로 맵을 끄려면 세 기능도 함께 꺼야 합니다.
