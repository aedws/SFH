# 장비 파츠·모듈 개조

## U 화면

작전 중 U 키로 장비·파츠·모듈 개조 화면을 엽니다. 화면은 **무기**와 **방어구** 탭으로 분리되며 게임은 열린 동안 일시정지됩니다.

무기 탭에서는 메인·보조 슬롯을, 방어구 탭에서는 신체·신발 슬롯을 선택합니다. 각 탭은 현재 장비 레벨, 파츠, 모듈 슬롯, 사용/최대 코스트, 개조 태그를 표시합니다.

## 장비 슬롯 태그

`EquipmentSlotRule`이 장착 가능 여부를 판정합니다.

| 슬롯 | 현재 허용 규칙 |
|---|---|
| 메인 | 원거리 > 화기 > 소총 |
| 보조 | 원거리 > 화기 > 권총 |
| 신체 | `body` 방어구 |
| 신발 | `feet` 방어구 |

아이템이 가방에서 차지하는 크기는 장착 판정에 관여하지 않습니다. 장착 탭은 무기 3단계 태그 또는 방어구 슬롯 태그만 검사합니다.

## 무기 고유 파츠

파츠는 `socket_id`와 호환 무기 소분류 목록을 가집니다.

- 소총 조준경: `rifle + optic`
- 권총 컴펜세이터: `pistol + muzzle`
- 대검 강화 날: `greatsword + blade`

무기 정의에도 사용할 수 있는 소켓 목록이 있습니다. 소분류가 다르거나 무기에 없는 소켓이면 장착할 수 없으며, 같은 소켓에는 파츠 하나만 허용합니다. 방어구는 파츠 장착 API를 항상 거부합니다.

## 모듈과 장착 코스트

무기와 방어구는 각각 다음 두 제한을 가집니다.

1. `module_slot_limit`: 장착 가능한 모듈 개수
2. `module_cost_limit`: 장착 모듈의 유효 코스트 합계

같은 모듈 ID는 한 장비에 중복 장착할 수 없습니다. 모듈은 범용 `stat_modifiers`와 아직 실행하지 않는 `special_feature_ids`를 함께 가질 수 있습니다.

## 모듈 강화

`cost_by_upgrade_level` 배열이 강화 단계별 코스트를 정의합니다. 예를 들어 `[4, 3, 2]`는 기본 코스트 4, 1강 3, 2강 2를 뜻합니다.

강화 재료와 재화는 아직 확정되지 않아 `upgrade_module()`은 규칙 적용만 담당합니다. 이후 경제 모듈이 비용을 검증한 다음 이 API를 호출하도록 연결합니다.

## 장비 레벨과 최고 레벨 개조

무기·방어구는 정의별 최고 레벨을 가집니다. 최고 레벨에 도달하면 `grant_module_tag()`로 개조 태그를 하나 이상 부여할 수 있습니다.

장착 모듈의 태그 중 하나가 장비 개조 태그와 맞으면 해당 모듈의 유효 코스트는 다음처럼 계산합니다.

```text
유효 코스트 = ceil(강화 단계 코스트 × 0.5)
```

태그가 여러 개 맞아도 반감은 한 번만 적용됩니다. 장비가 최고 레벨이 아니거나 빈 태그·중복 태그를 요청하면 개조를 거부합니다.

## 확장 경계

- 파츠·모듈의 능력치는 `EquipmentStatModifier`로 집계
- 특수 기능은 ID만 선언하고 향후 별도 실행기가 소비
- 레벨 경험치·강화 재료·비용은 장비 시스템 밖에서 승인
- 장비 변경 때 스킬 태그 호환성과 플레이어 스탯을 다시 계산
- 모든 상태는 슬롯별 `EquipmentItemState`에 격리

## 기능 토글과 의존성

`equipment_customization_enabled`는 `equipment_enabled`와 `inventory_enabled`가 모두 필요합니다. 끄면 U 화면만 설치되지 않고 기존 기본 로드아웃과 I 가방은 독립적으로 유지할 수 있습니다.
