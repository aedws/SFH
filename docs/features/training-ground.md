# P8 훈련 연습장

훈련장은 작전 보상·처치 수·일반 적 스폰 예산을 건드리지 않고 현재 장비의 전투 동작을 확인하는 거점 시설입니다. 플레이어는 거점의 **훈련장 단말에 F로 상호작용**해 다음 시나리오로 전환합니다.

| 시나리오 | 현재 임시 데이터 | 확인 목적 |
|---|---|---|
| 단일 중장 더미 | 1기 · HP 1,000 · 방어 25 | 보스 우선 타게팅과 단일 대상 피해 |
| 밀집 경량 더미 | 8기 · HP 240 · 방어 8 | 겹치지 않는 배치와 밀집 중심 자동 타게팅 |

두 행은 기존 `TrainingScenario` CSV를 그대로 사용합니다. 새 목록이 생기지 않아 Google Sheet는 확장하지 않았고, 수치는 `provisional`로 남겨 기획 확정 CSV 교체가 가능하게 했습니다.

## 플레이 흐름

1. 시작 거점에서 훈련장 단말로 이동합니다.
2. `F`로 단일 중장 더미를 생성합니다. 다시 상호작용하면 밀집 경량 더미로 전환됩니다.
3. 실제 좌클릭 공격과 스마트 자동 타게팅이 더미에게 적용됩니다.
4. 모든 더미를 처치하면 짧은 지연 뒤 같은 시나리오와 계측 시간이 함께 자동 초기화됩니다.
5. 우측 상단 계측 HUD에서 DPS·최대 타격·누적 피해·AP/s·평균 쿨타임을 확인합니다. 무료 시험 세팅은 그 아래, 압축 스킬 HUD는 우측 하단에 표시되어 서로 겹치지 않습니다.
6. `I/U/E`로 **보유** 장비·모듈·파츠를 편집하거나 훈련 스킬 버튼으로 호환 스킬을 순환합니다. 룬·코어·유물은 현재 가방/장착 상태에서 보유한 것만 표시합니다. 무료 장착 시 가방에서 꺼내고 해제 시 반환하며, 종료하면 이 임시 이동까지 원복합니다. 미보유 시 빈 목록 안내가 표시됩니다.
7. **종료·원복**, 다음 훈련, 작전 준비, 상점·준비 단말 이동 시 진입 전 상태로 복원합니다. 장비 창이 열려 있으면 먼저 저장/버리기/계속 편집을 선택합니다. 계속 편집은 훈련도 유지합니다.

훈련 더미는 경험치·드랍·처치 통계·방 보상·일반 적 생성 한도를 증가시키지 않습니다. 거점 밖 작전의 적 생성기와 전리품 생명 주기를 참조하지 않는 별도 경계입니다.

더미 생성 기준점은 훈련 단말에서 325px 떨어진 우측 시험 구역입니다. 실제 피해와 스킬 자원 소비는 전용 시간창에 누적되며, 측정 시간이 끝나면 결과가 고정되어 이후 입력이 같은 결과를 오염시키지 않습니다. 훈련 스킬 런타임은 실전 스킬 런타임의 복제본이므로 AP·충전·쿨타임은 재현하지만 영구 세팅과 다음 작전에는 영향을 주지 않습니다.

## 모듈 계약

2026-09-07 승인 임시 정책: `TrainingGroundConfig.owned_sockets_only=true`가 보유품 시험을 제한하고 `SessionSocketBindingPolicy`가 현재 무기/첫 스킬에 귀속합니다. 개발 샌드박스에서만 정책을 교체할 수 있으며 기본 플레이는 미보유 자산을 생성하지 않습니다. 훈련 UI와 I 가방은 같은 공개 소켓 명령을 사용합니다. 영구 룬 카탈로그나 새 Sheet 목록은 추가하지 않았습니다.

| 모듈 | 한 가지 책임 | 교체 지점 |
|---|---|---|
| `TrainingScenarioDefinition` | CSV 행 검증과 런타임 스냅샷 | 수치·시나리오 종류 |
| `TrainingDummySpawner` | 더미 소유·배치·생성·제거 | 더미 Scene·배치 알고리즘 |
| `TrainingScenarioResetService` | 수동/자동 초기화와 revision | 재생성 지연·정책 |
| `CombatTelemetryCollector` | 고정 시간창의 타격·자원 원시 집계 | DPS·AP/s 산식 |
| `TrainingTelemetryService` | 시간 진행·최종 스냅샷 고정 | 갱신 주기·측정 종료 |
| `TrainingTelemetryPresenter` | 읽기 전용 계측 HUD | 크기·표현·배치 |
| `TrainingLoadoutSnapshot` | 참여자 전체 검증·복사·실패 시 값 롤백 | export/validate/restore 계약 |
| `TrainingLoadoutService` | 세션 원본 보관·복원 재시도·저장 보호 | 장비/가방 + 추가 런타임 제공자 등록 |
| `CombatSkillSystem` / `CombatResourceSystem` | 스킬·쿨타임·AP·충전 복원, 지속 효과 정리 | 선택형 런타임 상태 계약 |
| `SessionSocketService` | 기존 RunAsset 카탈로그·슬롯·배율 적용/해제 | 훈련 전용 인스턴스, 실전과 소유 분리 |
| `DesktopProgressService` | 훈련 전 원본 저장·시험 중 자동 저장 격리 | 임시 로드아웃 begin/end 보호 구간 |
| `TrainingLoadoutPresenter` | 무료 세팅·스킬·소켓·종료 UI | 입력 표현, 규칙 계산 없음 |
| `TrainingSkillBindingAdapter` | 시험 스킬을 원래 슬롯의 사용자 키에 연결 | 영구 키 설정 읽기 전용·교체 후 입력 충돌 방지 |
| `TrainingHudLayout` | 뷰포트별 세 패널 위치·점유·비겹침 | 화면 여백·반응형 임계값 |
| `TrainingGroundService` | 위 계약 조립 façade | UI·Game이 호출하는 공개 계약 |
| `P5HubProgressionService` | 기존 훈련 목록·세션 신호 제공 | CSV 공급자 |
| `Game` | 거점 단말·실제 무기·피해 신호 연결 | Scene 조립만 담당 |

`FeatureManifest.training_ground_enabled`를 끄면 P5·거점·적·무기·장비 기능을 유지한 채 훈련장만 제거됩니다. 선행 기능이 비활성인 빌드에서는 훈련장을 자동 제외하므로 선택적 빌드가 전체 Manifest 오류로 바뀌지 않습니다.

## 검증

- `PROVISIONAL_POLICY_OK`: 미보유 거부·소유품 가방 반환, 무기/스킬 귀속, 미저장 편집 취소, 훈련 종료 가방·AP·소켓 원복. 훈련 복원 계약과 전체 플레이 E2E도 재실행했습니다.

- `P8_TRAINING_GROUND_OK`: 시나리오·비겹침·초기화와 실시간 DPS/AP, 시간 종료 결과 고정, 자동 재생성 시 새 계측 시작, 일반 스폰 비간섭, 선택 제거를 판정합니다.
- `E2E_P8_TRAINING_GROUND_OK`: 실제 거점 단말→좌클릭 타격→계측 HUD→뷰포트 내부/비겹침/84px 압축 배치→실제 스킬 AP/충전 소비→무료 변경→퇴장 복원→밀집 전환→이탈 정리를 판정합니다.
- `TRAINING_LOADOUT_RESTORE_OK`: 값 롤백·재시도, 저장 보호 해제 실패·재시도, 스킬/공용 소켓 복원, 반복 입장, 종료 버튼, 장비 초안 취소, 3개 화면 버튼 경계, 지속 가속 제거·AP 복원, 상점 이동, 초기화 실패 원복을 검사합니다.
- 2026-09-07 정적 모듈 감사: 기능 57개, 클래스 234개, 의존 26개, 순환 0, 서비스의 Scene 직접 참조 0, P8 경계 11개입니다. 전체 플레이 재미나 모든 확장 조합의 보증과는 다릅니다.

## N26-08A · 임시 세팅과 원본 보호 {#n26-08a}

2026-09-07 보완: 장비·가방뿐 아니라 스킬 정의/쿨타임/AP/충전과 공용 세션 소켓까지 복원 범위를 확장했습니다. Windows 자동 저장은 시험 중 장비로 원본을 덮어쓰지 않습니다. 훈련 도중 종료되어도 마지막 정상 장비 체크포인트를 유지하며 시험 아이템을 영구 획득 처리하지 않습니다.

- 복원 전에 모든 참여자를 검증합니다. 일부 실패 시 변경 직전 값으로 롤백하고, 원본 스냅샷·저장 보호를 보관합니다. UI는 **복원 대기**를 표시하고 종료 버튼으로 재시도합니다. 실패한 상태로 새 시험/작전 진입을 허용하지 않습니다.
- 복원은 값 상태 기준입니다. 활성 자기장·이동 가속은 취소하며 실패 재시도에서 이미 취소된 시각/시간 효과를 재생하지 않습니다. 기존 로비 장비 이외의 미보유 장비를 생성하지 않습니다.
- 같은 시나리오의 반복 입장 때 목록이 사라지던 참조 공유도 수정했습니다. 훈련 세션은 카탈로그 행의 사본을 소유합니다.
- 스킬을 바꿔도 해당 슬롯의 사용자 지정 키를 유지합니다. 예를 들어 점멸을 9번에 배치한 뒤 시험 스킬로 바꾸면 9번으로 발동하며, 다른 스킬의 기본 키와 겹치지 않습니다. 영구 키 설정은 수정하거나 저장하지 않습니다.
- 기존 스킬 목록·RunAsset·CSV/Web payload를 재사용합니다. Google Sheet 새 행/탭과 저장 스키마 변경은 없습니다. **장비별 소켓 귀속, 보유 룬 영구 목록, 더미 저항 편집** 등 잔여 기획은 이번 확정 범위가 아닙니다.

## N26-08B · 선택 기능 제거 후에도 훈련과 출격 {#n26-08b}

2026-09-07 후속 회귀에서 로드아웃 투자 기능 제거 시 빈 스킬 배열 타입 때문에 훈련 설치가 중단되는 오류를 수정했습니다. 스킬 실행기가 없으면 교체 버튼을 비활성화하고, 대체 가능한 스킬이 없으면 기존 스킬을 재선택해 쿨타임·충전을 초기화하지 않습니다.

- 시험이 활성인 동안 복원 제공자를 다시 구성할 수 없습니다. 원본 스냅샷의 소유권을 유지합니다.
- 키 어댑터 재구성 시 기존 Signal 연결과 원래 슬롯 목록을 정리해 중복 등록을 방지합니다.
- `TRAINING_OPTIONAL_MATRIX_OK`: 훈련장·공용 소켓·전투 자원·스킬 키 바인딩·로드아웃 투자 기능을 각각 제거한 5개 구성에서 거점, 훈련 종료, 브리핑 취소와 실제 중형 출격을 검사합니다. 런타임 오류와 미완성 HUD 설치도 실패입니다. 모든 선택 기능의 전수 조합 검증은 아닙니다.
- [CPU 성능 4개 조건](../performance/minimum-requirements.md)과 [통합 회귀·잔여 수락](../quality/e2e-play-session.md#n26-08b)을 분리 기록했습니다. **N26-08B 진행 중**이며 실제 렌더링 Web/Windows 10분 플레이는 남아 있습니다.
