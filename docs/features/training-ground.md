# P8 훈련 연습장

훈련장은 작전 보상·처치 수·일반 적 스폰 예산을 건드리지 않고 현재 장비의 전투 동작을 확인하는 거점 시설입니다. 플레이어는 거점의 **훈련장 단말에 F로 상호작용**해 다음 시나리오로 전환합니다.

| 시나리오 | 현재 임시 데이터 | 확인 목적 |
|---|---|---|
| 단일 중장 더미 | 1기 · HP 1,000 · 방어 25 | 보스 우선 타게팅과 단일 대상 피해 |
| 밀집 경량 더미 | 8기 · HP 240 · 방어 8 | 겹치지 않는 배치와 밀집 중심 자동 타게팅 |

두 행은 기존 `TrainingScenario` CSV를 그대로 사용합니다. 새 목록이 생기지 않아 Google Sheet는 확장하지 않았고, 수치는 `provisional`로 남겨 기획 확정 CSV 교체가 가능하게 했습니다.

## 플레이 흐름

1. 시작 거점에서 훈련장 단말로 이동합니다.
2. `F`로 단일 중장 더미를 생성합니다. 다시 상호작용하면 밀집 경량 더미로 전환됩니다.
3. 실제 좌클릭 공격과 스마트 자동 타게팅이 더미에게 적용됩니다.
4. 모든 더미를 처치하면 짧은 지연 뒤 같은 시나리오가 자동 초기화됩니다.
5. 우측 계측 HUD에서 DPS·최대 타격·누적 피해·AP/s·평균 쿨타임을 확인합니다.
6. `I/U/E` 또는 훈련 스킬 버튼으로 비용 없이 세팅을 바꿔 시험합니다.
7. 작전 준비로 나가거나 훈련을 종료하면 진입 전 장비·가방·스킬 상태로 자동 복원됩니다.

훈련 더미는 경험치·드랍·처치 통계·방 보상·일반 적 생성 한도를 증가시키지 않습니다. 거점 밖 작전의 적 생성기와 전리품 생명 주기를 참조하지 않는 별도 경계입니다.

더미 생성 기준점은 훈련 단말에서 325px 떨어진 우측 시험 구역입니다. 실제 피해와 스킬 자원 소비는 전용 시간창에 누적되며, 측정 시간이 끝나면 결과가 고정되어 이후 입력이 같은 결과를 오염시키지 않습니다. 훈련 스킬 런타임은 실전 스킬 런타임의 복제본이므로 AP·충전·쿨타임은 재현하지만 영구 세팅과 다음 작전에는 영향을 주지 않습니다.

## 모듈 계약

| 모듈 | 한 가지 책임 | 교체 지점 |
|---|---|---|
| `TrainingScenarioDefinition` | CSV 행 검증과 런타임 스냅샷 | 수치·시나리오 종류 |
| `TrainingDummySpawner` | 더미 소유·배치·생성·제거 | 더미 Scene·배치 알고리즘 |
| `TrainingScenarioResetService` | 수동/자동 초기화와 revision | 재생성 지연·정책 |
| `CombatTelemetryCollector` | 고정 시간창의 타격·자원 원시 집계 | DPS·AP/s 산식 |
| `TrainingTelemetryService` | 시간 진행·최종 스냅샷 고정 | 갱신 주기·측정 종료 |
| `TrainingTelemetryPresenter` | 읽기 전용 계측 HUD | 크기·표현·배치 |
| `TrainingLoadoutSnapshot` | 장비·가방의 진입 전 복사본 | 복원 대상 계약 |
| `TrainingLoadoutService` | 훈련 세션 시작·복원 | 장비/인벤토리 공급자 |
| `TrainingLoadoutPresenter` | 무비용 세팅 상태·스킬 순환 UI | 입력 표현 |
| `TrainingGroundService` | 위 계약 조립 façade | UI·Game이 호출하는 공개 계약 |
| `P5HubProgressionService` | 기존 훈련 목록·세션 신호 제공 | CSV 공급자 |
| `Game` | 거점 단말·실제 무기·피해 신호 연결 | Scene 조립만 담당 |

`FeatureManifest.training_ground_enabled`를 끄면 P5·거점·적·무기·장비 기능을 유지한 채 훈련장만 제거됩니다. 선행 기능이 비활성인 빌드에서는 훈련장을 자동 제외하므로 선택적 빌드가 전체 Manifest 오류로 바뀌지 않습니다.

## 검증

- `P8_TRAINING_GROUND_OK`: 시나리오·비겹침·초기화와 실시간 DPS/AP, 시간 종료 결과 고정, 일반 스폰 비간섭, 선택 제거를 판정합니다.
- `E2E_P8_TRAINING_GROUND_OK`: 실제 거점 단말→좌클릭 타격→계측 HUD→실제 스킬 AP/충전 소비→무료 변경→퇴장 복원→밀집 전환→이탈 정리를 판정합니다.
- 전체 모듈 감사: 기능 57개, 클래스 225개, 의존 26개, 순환 0, 서비스의 Scene 직접 참조 0, P8 경계 10개입니다.

P8-01~03은 구현과 E2E를 완료했습니다. 더미 수치·측정 시간은 계속 `provisional`이며 기획 확정 뒤 CSV만 교체합니다. 다음 내부 작업은 `P9-01` 도감 해금률·미해금 지역 힌트입니다.
