# 부분 체력 회복

기본 회복은 전투 긴장감을 없애지 않도록 제한적으로 적용됩니다.

| 항목 | 기본값 |
|---|---:|
| 피격 후 회복 대기 | 4초 |
| 초당 회복량 | 3 HP |
| 자연 회복 상한 | 최대 체력 65% |

회복 상한보다 체력이 높으면 자연 회복하지 않습니다. `생존 본능` 임시 버프의 즉시 회복은 별도이며 자연 회복 상한과 관계없이 적용됩니다.

## 모듈 경계

`HealthRecoverySystem`은 플레이어의 내부 체력 변수를 직접 읽지 않습니다. `health_changed` Signal과 `get_health_snapshot()`, `heal()` 공개 계약만 사용합니다. 대기 시간·초당 회복·상한은 `default_health_recovery.tres` Resource에서 조절합니다.

`FeatureManifest.health_recovery_enabled`만 끄면 피해, 체력 UI, 임시 버프는 유지하면서 자연 회복만 제거할 수 있습니다.
