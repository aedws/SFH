# 소모품 전용 체력 회복

2026-09-08 오너 지시 **“충돌은 노션에 맞추고”**에 따라 표준 생존 규칙을 변경했습니다. 이전 자연·드랍·레벨업 회복 복구 지시를 이 범위에서 대체합니다. 출격 전에 런 유틸에서 키트를 선택하고 HP 옆 `KIT 수량` 버튼으로 사용합니다.

| 원인 | 표준 작전 동작 |
|---|---|
| 지참 키트 | 클릭/터치로 1개 사용. 기존 Utility 데이터35 HP·최대2개·투입30C 유지 |
| 자연·드랍·레벨업·버프 HP 회복 | 차단. HP 결정은 생성하지 않음 |
| 부상 후 최대 HP 장비·버프 변경 | 현재 HP를 늘리지 않으며 최대치 감소 시 상한만 적용 |
| 새 플레이어 생성·훈련 원복 | 초기화/원본 복원. 작전 중 회복 수단이 아님 |
| AP·스킬 충전 | 기존 독립 정책 유지 |

최대 HP·사망·작전 외·수량 부족일 때는 사용/차감을 거부합니다. 회복 감소 페널티는 실제 회복량에 곱합니다. 기존 Utility 수치는 임시 값이며 새 밸런스 확정이 아닙니다. 혈전·흡혈은 이번 승인 범위가 아닙니다.

## 모듈 경계

Player의 `PlayerHealthRecoveryPolicy` Resource가 허용 원인을 소유하며 기본값은 `consumable`만입니다. `heal(amount, source)`는 유한한 양수·살아 있는 대상·허용 원인만 적용합니다. 누락/알 수 없는 원인·null 정책은 거부합니다. 생산자는 `can_receive_healing(source)`로 미리 판정합니다.

자연 회복·드랍·레벨업·버프 모듈은 명명된 원인으로 요청합니다. 회복 모듈을 꺼도 Player의 정책은 유지됩니다. `UtilityInvestmentService.use_healing`은 조건 검증·수량 차감·회복을 처리하고 `MedkitButton`은 공개 서비스만 호출합니다. Game은 조립만 담당합니다.

기존 재생 Resource·버프 CSV는 대체 프로필 확장을 위해 보존하지만 표준 정책에서는 회복을 허용하지 않습니다. 증강 카드에 HP 회복 미적용을 표시합니다. 새 목록이 없어 Sheet 구조는 늘리지 않았습니다.

## 검증

`kit_only_health_contract_test.gd`: 원인 게이트·잘못된 수치·부상 최대치·키트 차감·최대 HP·사망·작전 종료·정책 격리와 소/중/대 Game의 KIT 버튼을 검사합니다. 스모크·게임플레이 E2E도 수행합니다. 첫 GPU 프레임·배포 Web/Windows 각각10분 일반 플레이는 별도 검수이며 헤드리스 조립 시간으로 대체하지 않습니다.
