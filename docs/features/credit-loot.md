# 크레딧 파밍과 회수

## 플레이 흐름

1. 맵 생성기가 방해물과 겹치지 않는 파밍 좌표를 제공합니다.
2. `LootSpawner`가 작전 등급에 맞춰 여러 보급 상자를 무작위 배치합니다.
3. 상자 가까이에서 `F`를 누르면 크레딧을 한 번만 획득합니다.
4. 획득한 값은 HUD의 `휴대 크레딧`에 표시됩니다.
5. 탈출에 성공하면 휴대 크레딧을 회수합니다.
6. 체력이 0이 되면 휴대 크레딧을 모두 분실합니다.

## 등급별 설정

| 작전 | 상자 수 | 상자당 크레딧 |
|---|---:|---:|
| 소형 | 4~6 | 15~35 |
| 중형 | 7~10 | 25~55 |
| 대형 | 11~16 | 40~80 |

수치는 `game/features/loot/configs/`의 `LootTierConfig` Resource에서 조절합니다. 맵 크기 수치와 파밍 보상 수치를 서로 다른 Resource로 분리해 두 기능이 독립적으로 밸런싱되게 했습니다.

## 모듈 경계

- 맵: 걸을 수 있고 방해물이 없는 월드 좌표 제공
- 파밍: 상자 수, 가치, 1회성 F 상호작용
- 크레딧 원장: 휴대·회수·분실 상태와 Signal
- 탈출: 성공 사건만 알림
- `Game`: Signal을 연결하고 결과 문구 조립

`LootSpawner`는 방 배열이나 A* 객체를 읽지 않으며 `get_loot_spawn_positions(count)` 계약만 사용합니다.

## 기능 토글

- `credits_enabled`: 작전 크레딧 원장과 HUD
- `loot_enabled`: 보급 상자 생성과 F 파밍

`loot`는 `credits`와 `map_generation`에 의존합니다.

## 현재 제한

회수한 크레딧은 작전 결과까지 계산되지만 아직 계정 저장 파일에는 기록하지 않습니다. 영구 지갑과 진입 비용 차감은 다음 경제 시스템 단계에서 연결합니다.

## 검색 별칭

돈 파밍, 재화, 골드, 크레딧 상자, 루팅, 보급품, F 수색, 회수 보상, 분실
