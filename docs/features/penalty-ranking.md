# 페널티 변형과 조건부 랭킹

작전 전 최대 3개 페널티를 선택할 수 있습니다. 현재 UI는 한 개를 순환 선택하며 시스템 계약은 복수 선택을 지원합니다.

| 페널티 | 적 변화 | 회수 배율 |
|---|---|---:|
| 강화 장갑 | 장갑 ×1.50 | ×1.25 |
| 포식성 추격 | 피해 ×1.30, 속도 ×1.18 | ×1.35 |
| 생체 증식 | 체력 ×1.60 | ×1.30 |
| 회복 억제 | 체력·에너지 회복량 감소 | ×1.20 |
| 협소 시야 | 통로 시야 반경·정면 시야 감소 | ×1.25 |
| 지연 탈출 | 탈출 방어 카운트다운 증가 | ×1.30 |

난이도 배율과 페널티 배율은 곱으로 합성합니다. 회복·시야·탈출 수정자도 각 시스템의 공개 배율 계약에 한 번만 전달됩니다. 선택 제한, 위험 점수와 수치는 `PenaltyConfig` Resource로 변경합니다.

## 조건부 랭킹

성공 작전만 기록하며 지역·난이도·맵 규모가 같고 최소 페널티 점수 10 이상인 기록끼리 비교합니다. 조건마다 다음 세 개의 상위 20개 목록을 독립 저장합니다.

| 종목 | 정렬 |
|---|---|
| 회수 가치 | 높은 값 우선 |
| 최단 탈출 시간 | 낮은 값 우선 |
| 처치 수 | 높은 값 우선 |

최소 페널티 점수, 종목 ID·정렬 방향과 조건별 보관 개수는 `ConditionalRankingPolicy` Resource에 있고, 시스템은 주입된 정책 결과만 정렬·저장합니다. 이전 단일 종합 점수 JSON은 로드할 때 세 종목 구조로 이관됩니다. 향후 서버 랭킹을 붙일 때 로컬 저장 구현을 같은 제출·조회 계약의 원격 제공자로 교체합니다.
