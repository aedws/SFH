# 경험치와 레벨

## 흐름

```text
적 사망 → 경험치 결정 생성 → 플레이어에게 자석 이동 → 획득 → 레벨 증가
```

경험치 결정은 플레이어가 가까이 접근하면 자동으로 끌려옵니다. 레벨이 오르면 현재 최소 구현에서는 체력을 일부 회복하고 자동 무기를 강화합니다.

## 모듈 구성

- `ExperiencePickup`: 필드의 경험치 결정
- `ProgressionSystem`: 현재 경험치, 요구 경험치, 레벨 관리

## 활성화와 의존성

- `experience_enabled`: 결정 생성과 경험치 획득
- `leveling_enabled`: 요구 경험치를 채웠을 때 레벨 증가

`leveling`은 `experience` 없이 켤 수 없습니다.
