# SFH / 작전과 맵

거점에서 출격을 준비하고, 방과 통로로 이루어진 작전 지역을 탐험한 뒤 탈출하는 흐름을 설명합니다.

[TOC]

## 1. 처음 읽는 순서

**현재 작전 기본형:** [익스트랙션 구역과 공간 공개](extraction-district.md). 일반 시설은 후퇴 가능, 금고만 선택 봉쇄, 두 출구는 처음부터 현장 방어를 시작할 수 있습니다.

1. [시작 거점](start-hub.md)에서 작전 게이트를 찾습니다.
2. [작전 진입 안내](operation-entry-wizard.md)에서 지역·장비·최종 조건을 확인합니다.
3. 전장에서 [지도](minimap.md)와 [시야](fog-of-war.md)를 확인하고, [탈출 방어전](extraction-defense-results.md)을 거쳐 돌아옵니다.
