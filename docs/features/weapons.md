# 자동 무기

## 총기·근거리 무기 8종 {#arsenal-20260909}

2026-09-09 오너 요청으로 **총기 5종 + 근접 3종**을 실제 공격·드랍·장착에 연결했습니다. 기존 단검/대검은 정의만 있고 밸런스 비활성 상태라 소총 폴백이 적용되던 상태였습니다. 지금은 탄환을 생성하지 않는 베기/찌르기입니다. 아래 수치는 기획 최종 확정이 아닌 **임시 플레이 시험값**입니다.

| 무기 | 플레이 차이 | 기본 피해 / 주기 | 기본 사거리 | 판정 |
|---|---|---|---|---|
| 돌격소총 | 안정적인 3점사 | 1.6 × 3 / 0.78초 + 점사 간격 | 820px | 기존 탄환 |
| 제식 권총 | 강한 단발·1회 관통 | 3.2 / 0.60초 | 560px | 기존 탄환 |
| 전격 펄스 소총 | 빠른 사격·명중 전기 광역 | 1.15 / 0.34초 | 760px | 기존 탄환 |
| 돌파 산탄총 | 가까이 붙을수록 산탄 집중 | 1.3 × 5 / 0.85초 | 350px | 24도 부채꼴 5발 |
| 관통 레일 소총 | 긴 거리·느린 고위력·최대 4명 | 7.0 / 1.10초 | 1000px | 3회 관통, 다음 대상 80% |

| 전격 관통창 | 좁고 긴 찌르기·명중 누적 방전 | 4.8 / 0.58초 | 185px | 전방 직선, 최대 4명 |

표는 고정 옵션·모듈·치명타·성장·거리 보정 전입니다. 실제 조합은 [DPS/성장 계산기](../tools/balance-workbench.md)에서 한 무기를 선택해 확인합니다. 단일 적 기준 계산이며 다수 적 총 피해는 배치·명중률에 따라 달라집니다. 근접 사거리는 탄속×수명이 아닌 실제 타격 범위로 계산합니다.

### 어떻게 얻고 사용하는가

로비에서 `I/U`로 주무기를 장착한 뒤 그대로 출격합니다. 주무기는 근접/원거리 전체를 수용하고 보조는 기존 권총 슬롯입니다. 출격 UI가 무기를 다시 선택하거나 덮어쓰지 않습니다. `Q`로 슬롯을 바꾸고 좌클릭을 누르면 사거리 내 적 방향으로 자동 공격합니다.

기존 Windows 저장 파일의 기본 주무기 슬롯도 자동 갱신합니다. `EquipmentSlotPolicyMigration`은 버전 표시가 없는 이전 기본 소총 전용 규칙만 사본에서 변경합니다. 보유 장비·강화 레벨·활성 슬롯은 유지하며 별도 로드아웃이나 버전이 지정된 사용자 규칙은 덮어쓰지 않습니다.

단검·산탄총·레일 소총·창은 세 지역 모두 **방 보상과 보스 보상**에 실물 후보로 추가했습니다. 방 보상은 기존 무기→방어구→모듈→파츠 분류 순환을 유지하므로 모든 보상마다 무기가 확정되는 것은 아닙니다. 일반 적은 현재 무기 드랍 행이 없습니다. 획득 후 가방·장착·탈출 창고/사망 소실 정책을 그대로 적용합니다.

### 참조한 원리와 자체 구현

[Enter the Gungeon 공식 소개](https://www.nintendo.com/en-gb/Games/Nintendo-Switch-download-software/Enter-the-Gungeon-1320155.html)의 무기별 다른 운용 방식, [The First Descendant 개발 노트](https://tfd.nexon.com/en/news/2130481)의 근거리 산탄/장거리 고위력처럼 거리와 공격 리듬을 구분하는 원리를 참조했습니다. 무기명·이미지·게임 에셋은 복제하지 않았으며 근접 베기와 창 찌르기는 본 게임의 자동 조준에 맞춘 자체 구현입니다.

### 모듈 경계

`Weapon.attack_mode` → `WeaponBalanceTable` 검증 → `AutoWeapon` 공통 공격 주기 → 탄환 또는 `WeaponMeleeStrike`로 분기합니다. `MeleeStrikePolicy`는 위치/방향 기하만 판단합니다. 타격기는 월드 벽(레이어 16) 차폐·중복 제거·가까운 순 대상 상한·거리 피해를 처리하고, 짧은 궤적 FX는 피해를 재적용하지 않습니다. 고유 효과는 공통 명중 신호와 발동 당시 정체성 사본을 사용합니다.

새 근접 무기는 기존 공격 모드와 Resource/Sheet 행으로 추가합니다. Game 조립부에 무기 ID 분기를 추가하지 않습니다. 밸런스 기능을 끈 경우에도 잠금 payload에서 동일 무기의 공격을 복원합니다. 새로운 종류의 공격 자체는 별도 실행 모듈·검증을 추가해야 합니다. 직접 타격의 벽 차폐와 고유 전기 광역의 기존 범위 정책은 별개입니다.

### 검증과 남은 확인

[무기 다양화 회귀](../quality/e2e-play-session.md#arsenal-20260909)는 8종 실제 입력·명중, 산탄 5발, 근접 무탄환·벽·후방·거리·중복·대상 상한·미래 ID 확장과 216개 신규 드랍 후보 경로를 검사합니다. 장시간 난이도/재미 밸런스의 최종 승인은 별도이며 자동 통과를 사람의 재미 검수 완료로 표시하지 않습니다.

## 목적

플레이어가 마우스 왼쪽 버튼을 누르는 동안 스마트 타게팅 정책으로 대상을 찾아 공격 속도에 맞춰 연속 발사합니다. 조준 방향을 직접 맞추지는 않지만 공격 시작과 중지는 플레이어가 결정합니다.

## 구성

```text
AutoWeapon
├─ Projectile → 총기 탄환
└─ WeaponMeleeStrike → MeleeStrikePolicy + 베기/찌르기 FX
```

`AutoWeapon`은 게임에서는 주입된 대상 제공자와 `SmartTargetingPolicy`를 사용하며 단독 Scene 실행에서만 `enemies` 그룹으로 폴백합니다. 투사체는 대상이 `take_damage` 메서드를 제공하는지만 확인합니다.

런타임 스냅샷은 누적 발사 묶음, 실제 생성한 발사체 수와 마지막 대상 인스턴스를 읽기 전용으로 제공합니다. 실제 입력 E2E는 물리 마우스 1을 누른 뒤 이 수치와 타격 이펙트·치명 타격·처치·자원 드랍이 모두 증가해야 통과합니다. 발사체 충돌 중 발생한 드랍은 Godot 물리 쿼리를 방해하지 않도록 다음 안전 프레임에 생성합니다.

## 조정 가능한 값

- 피해, 발사 사이클, 자동 탐지 거리
- 투사체 속도·수명·색상
- 회당 투사체 수와 고정 분산각
- 버스트 수와 버스트 내부 간격
- 치명타 확률·배율
- 관통 횟수와 관통 후 피해 유지율
- 좌클릭 홀드 필요 여부와 타게팅 정책 ID

레벨이 상승하면 공격 간격이 감소하고 일정 레벨마다 피해가 증가합니다.

## 장비 무기와의 관계

[캐릭터 장비와 로드아웃](character-equipment.md)의 메인·보조 무기 Resource는 이름과 대·중·소분류 태그 외에 전투 태그, 등급과 스킬 메커니즘 변경표를 소유합니다. `Q`로 활성 슬롯을 바꾸면 `AutoWeapon`이 해당 `weapon_id`의 밸런스와 타게팅 모드를 적용하고 스킬 호환 상태도 다시 계산합니다.

각 무기는 같은 `weapon_id`에서 항상 같은 고유 스킬과 기본 고정 옵션을 가집니다. 투사체는 발사 시점의 정체성을 보존하며 무기별 총구 섬광·광원·충격 색과 반응 강도를 사용합니다. 성장·모듈과 분리된 계산 계약은 [무기 고유 스킬과 장비 고정 옵션](equipment-fixed-identity.md)을 확인합니다.

수치 출처와 확정 절차는 [Q 무기 교체와 Google Sheets 밸런스](weapon-balance.md)에서 확인합니다.

## 비활성화

`FeatureManifest.weapons_enabled`를 끄면 무기 Scene을 플레이어에게 설치하지 않습니다.
