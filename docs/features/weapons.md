# 자동 무기

## 목적

플레이어가 마우스 왼쪽 버튼을 누르는 동안 스마트 타게팅 정책으로 대상을 찾아 공격 속도에 맞춰 연속 발사합니다. 조준 방향을 직접 맞추지는 않지만 공격 시작과 중지는 플레이어가 결정합니다.

## 구성

```text
AutoWeapon
└─ Projectile 인스턴스 → World/Projectiles에 생성
```

`AutoWeapon`은 게임에서는 주입된 대상 제공자와 `SmartTargetingPolicy`를 사용하며 단독 Scene 실행에서만 `enemies` 그룹으로 폴백합니다. 투사체는 대상이 `take_damage` 메서드를 제공하는지만 확인합니다.

런타임 스냅샷은 누적 발사 묶음, 실제 생성한 발사체 수와 마지막 대상 인스턴스를 읽기 전용으로 제공합니다. 실제 입력 E2E는 물리 마우스 1을 누른 뒤 이 수치와 타격 이펙트·치명 타격·처치·자원 드랍이 모두 증가해야 통과합니다. 발사체 충돌 중 발생한 드랍은 Godot 물리 쿼리를 방해하지 않도록 다음 안전 프레임에 생성합니다.

## 조정 가능한 값

- 피해, 발사 사이클, 자동 탐지 거리
- 투사체 속도·수명·색상
- 회당 투사체 수와 고정 분산각
- 버스트 수와 버스트 내부 간격
- 치명타 확률·배율
- 관통 횟수와 관통 후 피해 유지율
- 좌클릭 홀드 필요 여부와 타게팅 정책 ID

레벨이 상승하면 공격 간격이 감소하고 일정 레벨마다 피해가 증가합니다.

## 장비 무기와의 관계

[캐릭터 장비와 로드아웃](character-equipment.md)의 메인·보조 무기 Resource는 이름과 대·중·소분류 태그 외에 전투 태그, 등급과 스킬 메커니즘 변경표를 소유합니다. `Q`로 활성 슬롯을 바꾸면 `AutoWeapon`이 해당 `weapon_id`의 밸런스와 타게팅 모드를 적용하고 스킬 호환 상태도 다시 계산합니다.

각 무기는 같은 `weapon_id`에서 항상 같은 고유 스킬과 기본 고정 옵션을 가집니다. 투사체는 발사 시점의 정체성을 보존하며 무기별 총구 섬광·광원·충격 색과 반응 강도를 사용합니다. 성장·모듈과 분리된 계산 계약은 [무기 고유 스킬과 장비 고정 옵션](equipment-fixed-identity.md)을 확인합니다.

수치 출처와 확정 절차는 [Q 무기 교체와 Google Sheets 밸런스](weapon-balance.md)에서 확인합니다.

## 비활성화

`FeatureManifest.weapons_enabled`를 끄면 무기 Scene을 플레이어에게 설치하지 않습니다.
