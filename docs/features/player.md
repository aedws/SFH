# 플레이어 이동

## 목적

키보드 입력을 받아 탑다운 8방향으로 이동합니다. 일반 뱀서라이크의 단순 정속 이동 대신 핵앤슬래시의 즉각적인 초동, 강한 급선회, 짧은 회피와 회피 종료 관성을 탑다운 이동에 맞게 적용했습니다.

## 조작

- 이동: `WASD` 또는 방향키
- 회피 이동: `Shift` 또는 `Space`
- 대각선 이동 속도는 정규화되어 직선 이동과 같습니다.
- 입력 순간 기본 속도의 38%를 확보한 뒤 빠르게 가속하고, 손을 떼면 강하게 감속합니다.
- 방향을 크게 꺾으면 일반 가속보다 강한 선회 가속, 정반대 방향에는 가장 강한 역선회 응답을 적용합니다.
- 회피는 입력 방향을 잠그고 0.14초간 2.35배 속도를 내며 기본 재사용 대기시간은 0.85초입니다.
- 회피가 끝난 뒤 0.18초 동안 최대 1.22배의 감쇠 관성을 남겨 동작이 갑자기 끊기지 않습니다.

## 구성

```text
Player (CharacterBody2D)
├─ Movement (Node)
├─ Body (Polygon2D)
├─ Heading (Polygon2D)
├─ CollisionShape2D
└─ Camera2D
```

`PlayerCharacter`는 물리 이동과 런타임 스탯 적용을 담당하고, `PlayerMovement`는 입력, 가속·제동, 선회, 회피 상태만 담당합니다. `step_velocity()`가 입력 방향과 현재 속도를 받아 결과 속도를 반환하므로 이동 수치를 독립 테스트하거나 다른 캐릭터에 재사용할 수 있습니다.

## 설정

`Player/Movement` Node를 선택하면 이동 속도, 일반·선회·역선회 가속, 제동, 초동 속도 비율, 회피 속도·시간·쿨다운, 회피 종료 관성을 각각 조절할 수 있습니다. 현재 기본값은 이동 속도 280px/s, 일반 가속 3,200, 선회 4,200, 제동 4,200, 역선회 7,200입니다.

기본 스탯은 최대 체력 100, 방어 0, 이동 속도 280입니다. [캐릭터 장비와 로드아웃](character-equipment.md)이 `apply_equipment_modifiers` 계약을 통해 작전 시작 시 수정합니다. 현재 기본 장비 적용 후 값은 최대 체력 125, 방어 3, 이동 속도 300입니다.

`get_movement_snapshot()`은 조정값과 회피 준비·종료 관성 상태를 복사해 제공합니다. 자동 테스트는 초동 가속, 정지 제동, 180도 역선회, 90도 선회, 회피 속도와 종료 관성을 입력 장치 없이 `step_velocity()`로 검증합니다.

## 의존성

- Godot 기본 `ui_left`, `ui_right`, `ui_up`, `ui_down` 입력
- `game/scenes/game.gd`의 플레이어 설치 지점
- `FeatureManifest.player_enabled`
- 장비가 켜진 경우 `apply_equipment_modifiers(modifiers)` 공개 계약

## 비활성화

`game/core/feature_manifest.tres`를 열고 `Player Enabled`를 끕니다. 그러면 실행 시 플레이어 Scene을 생성하지 않습니다.
