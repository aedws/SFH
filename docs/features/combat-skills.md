# 전투 스킬과 쿨타임 HUD

작전 중 숫자 `1`~`9`를 액티브 스킬 슬롯으로 사용합니다. 현재 기본 콘텐츠는 `1` 점멸, `2` 원형 자기장, `3` 기동 가속 세 개이며 `4`~`9`는 이후 정의를 꽂을 수 있는 빈 입력 계약입니다. 화면 아래 중앙에는 실제 장착된 스킬의 키, 이름, 역할과 남은 재사용 시간이 표시됩니다.

키 입력은 `CombatSkillDefinition`과 `CombatSkillSystem.rebind_slot()`으로 분리되어 런타임 교체가 가능합니다. 현재 남은 작업은 사용자가 직접 여는 키 설정 화면과 변경값의 영구 저장입니다.

## 기본 스킬 세트

| 키 | 스킬 | 현재 효과 | 쿨타임 | 에너지 | 충전 |
|---:|---|---|---:|---:|---:|
| `1` | 점멸 | 바라보는 방향으로 최대 360px 순간 이동. 이동 경로 폭 80px 안의 적 최대 24명에게 12 피해를 주고 벽 앞에서 정지 | 5초 | 20 | 2회·7초 |
| `2` | 원형 자기장 | 5초 동안 자신을 따라오는 반경 230px 전기장. 0.5초마다 적에게 6 피해를 누적 | 8초 | 35 | 1회·10초 |
| `3` | 기동 가속 | 4초 동안 이동 속도 55% 증가하며 캐릭터를 따라가는 전기 방출 표시 | 12초 | 25 | 2회·14초 |

스킬 발동 직후 HUD는 `READY` 대신 소수점 한 자리의 남은 시간을 표시합니다. 쿨타임·에너지·충전이 모두 준비돼야 다시 `READY`가 되며, 전체 에너지 막대와 슬롯별 `EN` 소비량·충전 수를 함께 표시합니다. `EN`은 Web 폰트에서 빠질 수 있는 번개 이모지를 사용하지 않는 고정 표기입니다. 상세 회수 규칙은 [전투 에너지·충전·회복 드랍](combat-resources.md)을 참고합니다.

## 사용 흐름

1. 시작 거점에서 작전 게이트를 통해 전투 세션에 진입합니다.
2. 이동 방향이 점멸의 전방 기준이 됩니다.
3. 다수 적이 접근하면 `2`를 켜고 이동해 지속 범위 안에 적을 유지합니다.
4. 추격·이탈이 필요하면 `3`으로 이동 속도를 높입니다.
5. 스킬이 준비되지 않았을 때 같은 키를 눌러도 중복 발동하지 않습니다.

## 모듈 구조

```text
CombatSkillLoadout Resource
  └─ CombatSkillDefinition Resource × 3
       └─ CombatSkillEffect Resource
            ├─ ElectricEffectProfile Resource
            └─ PathDamagePolicy Resource   # 점멸 경로 피해량·폭·최대 타격 수

CombatSkillSystem
  ├─ 입력과 쿨타임만 관리
  ├─ 1~9 슬롯 바인딩과 런타임 재설정
  ├─ 장비 태그 호환·등급별 메커니즘 변경 조회
  ├─ 유형별 SmartTargetingPolicy 컨텍스트 구성
  ├─ Player·Enemies·EffectParent 공개 참조를 주입받음
  ├─ CombatResourceSystem의 can_activate / consume_for_skill 계약 사용
  └─ skill_states_changed / skill_activated Signal

CombatSkillHud
  └─ get_skill_states() 결과만 표현
```

- 점멸, 자기장, 기동 가속은 서로 다른 효과 스크립트이므로 하나만 교체할 수 있습니다.
- 점멸 경로 피해는 이동 효과가 직접 수치를 소유하지 않고 `PathDamagePolicy`를 주입받습니다. 정책을 제거하면 이동 전용 점멸로 돌아갑니다.
- 수치와 키·이름·설명은 `.tres` 정의에서 변경합니다.
- 경로·범위 공격은 대상이 `take_damage()` 계약을 제공하는지만 확인합니다.
- 자기장 정의는 지속 시간·틱 간격·틱 피해만 주입하고, `PersistentMagneticField`가 추적과 누적 피해를 담당합니다.
- 이동 가속은 플레이어의 기존 수정자 출처 계약을 사용하며 장비·런 버프 계산을 덮어쓰지 않습니다.
- `combat_skills_enabled`를 끄면 실행기와 하단 HUD가 함께 설치되지 않으며 나머지 전투는 유지됩니다.
- `combat_resources_enabled`만 끄면 에너지·충전 정책 없이 기존 쿨타임 전용 스킬로 돌아갑니다.
- 현재 무기가 스킬의 `required_combat_tags`를 모두 충족하지 않으면 발동하지 않으며 HUD에 `무기 태그 불일치`가 표시됩니다.
- 상위 등급 무기는 스킬 ID별 메커니즘 수정자를 제공할 수 있습니다. 예를 들어 같은 점멸도 이동 거리와 경로 피해가 달라질 수 있습니다.
- 자기장이 부여한 `shock`를 점멸 경로 피해가 소비해 추가 피해를 주고 `ionized`를 남깁니다. 상태 저장, 소비와 효과 수치는 각각 적·효과 정책에 격리되어 있습니다.

## 전기 이펙트 프로필

세 스킬은 같은 `ElectricArcEffect` 렌더러를 사용하지만 서로 다른 `.tres` 프로필을 주입받습니다. 따라서 스킬 로직을 건드리지 않고 패턴·색·수명·선분 밀도와 갱신 빈도를 바꿀 수 있습니다.

| 스킬 | 패턴 | 수명·갱신 | 선분 예산 |
|---|---|---:|---:|
| 점멸 | 출발점에서 도착점까지 전기 잔상 `trail` | 0.32초 · 20Hz | 15 |
| 원형 자기장 | 플레이어를 따라 지속되는 전기 고리 `ring` | 5초 · 16Hz | 40 |
| 기동 가속 | 플레이어를 추적하는 방사형 전기 `burst` | 4초 · 10Hz | 16 |

프로필은 최대 128개 선분만 허용합니다. 형상은 매 프레임 새로 만들지 않고 지정한 10~20Hz에서만 다시 생성해 캐시하며, 프레임 사이에는 투명도와 추적 위치만 변경합니다. 동시에 존재하는 기본 전기 효과는 최대 3개로 성능 테스트에서 제한합니다.

## 쿨타임·범위 처리 최적화

- 쿨타임 계산은 매 프레임 유지하되 HUD 상태 Signal은 최대 10Hz와 발동·준비 완료 순간에만 전송합니다.
- 기동 가속 종료는 매 프레임 감소시키는 Node 대신 one-shot `Timer`가 처리합니다.
- 자기장은 0.5초 피해 틱에서만 `get_children()` 임시 배열 없이 컨테이너 인덱스로 대상을 순회합니다.
- 점멸 경로 판정은 발동 순간에만 수행하고 정책의 최대 타격 수 24에서 중단합니다.
- 대형 작전 프레임·Node·이펙트 예산은 [최소·권장 사양과 성능 예산](../performance/minimum-requirements.md)에서 별도로 검증합니다.

## 장비 스킬과의 관계

장비의 기존 대·중·소분류 태그는 아이템 장착 호환성을, 전투 태그(`melee`, `projectile`, `slash`, `blunt`, `element`, `electric`)는 실제 스킬 발동 호환성을 담당합니다. `Q`로 활성 무기를 바꾸면 전투 스킬 시스템이 장비 공개 계약을 다시 조회해 슬롯 준비 상태를 즉시 갱신합니다. 슬롯 최대 수는 9이며 정의와 효과 Resource는 서로 독립입니다.

## 확장 지점

- 체력 소모·과충전·자원 변환 같은 추가 비용 정책
- 사용자용 키 설정 UI와 바인딩 영구 저장
- 기본 콘텐츠 4~9번 스킬과 추가 전투 태그 조합
- 원형 자기장의 선택형 끌어당김 메커니즘
- Google Sheets 기반 스킬 수치 실시간 테스트
- 상태 연계 규칙을 별도 조합표로 확장
