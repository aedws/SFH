# 전투 스킬과 쿨타임 HUD

작전 중 숫자 `1`, `2`, `3`으로 세 가지 전투 스킬을 직접 사용합니다. 화면 아래 중앙에는 각 스킬의 키, 이름, 역할과 남은 재사용 시간이 항상 표시됩니다.

## 기본 스킬 세트

| 키 | 스킬 | 현재 효과 | 재사용 시간 |
|---:|---|---|---:|
| `1` | 점멸 | 바라보는 방향으로 최대 360px 순간 이동. 벽을 감지하면 벽 앞에서 정지하고 청백색 전기 잔상을 남김 | 5초 |
| `2` | 원형 자기장 | 자신을 중심으로 반경 230px 안의 적에게 24 범위 피해와 원형 전기장을 전개 | 8초 |
| `3` | 기동 가속 | 4초 동안 이동 속도 55% 증가하며 캐릭터를 따라가는 전기 방출 표시 | 12초 |

스킬 발동 직후 HUD는 `READY` 대신 소수점 한 자리의 남은 시간을 표시합니다. 쿨타임이 끝나면 진행 막대가 가득 차고 다시 `READY`가 됩니다.

## 사용 흐름

1. 시작 거점에서 작전 게이트를 통해 전투 세션에 진입합니다.
2. 이동 방향이 점멸의 전방 기준이 됩니다.
3. 다수 적이 접근하면 `2`로 원형 범위 피해를 가합니다.
4. 추격·이탈이 필요하면 `3`으로 이동 속도를 높입니다.
5. 스킬이 준비되지 않았을 때 같은 키를 눌러도 중복 발동하지 않습니다.

## 모듈 구조

```text
CombatSkillLoadout Resource
  └─ CombatSkillDefinition Resource × 3
       └─ CombatSkillEffect Resource
            └─ ElectricEffectProfile Resource

CombatSkillSystem
  ├─ 입력과 쿨타임만 관리
  ├─ Player·Enemies·EffectParent 공개 참조를 주입받음
  └─ skill_states_changed / skill_activated Signal

CombatSkillHud
  └─ get_skill_states() 결과만 표현
```

- 점멸, 자기장, 기동 가속은 서로 다른 효과 스크립트이므로 하나만 교체할 수 있습니다.
- 수치와 키·이름·설명은 `.tres` 정의에서 변경합니다.
- 범위 공격은 대상이 `take_damage()` 계약을 제공하는지만 확인합니다.
- 이동 가속은 플레이어의 기존 수정자 출처 계약을 사용하며 장비·런 버프 계산을 덮어쓰지 않습니다.
- `combat_skills_enabled`를 끄면 실행기와 하단 HUD가 함께 설치되지 않으며 나머지 전투는 유지됩니다.

## 전기 이펙트 프로필

세 스킬은 같은 `ElectricArcEffect` 렌더러를 사용하지만 서로 다른 `.tres` 프로필을 주입받습니다. 따라서 스킬 로직을 건드리지 않고 패턴·색·수명·선분 밀도와 갱신 빈도를 바꿀 수 있습니다.

| 스킬 | 패턴 | 수명·갱신 | 선분 예산 |
|---|---|---:|---:|
| 점멸 | 출발점에서 도착점까지 전기 잔상 `trail` | 0.32초 · 20Hz | 15 |
| 원형 자기장 | 반경을 따라 끊어지는 전기 고리 `ring` | 0.75초 · 16Hz | 40 |
| 기동 가속 | 플레이어를 추적하는 방사형 전기 `burst` | 4초 · 10Hz | 16 |

프로필은 최대 128개 선분만 허용합니다. 형상은 매 프레임 새로 만들지 않고 지정한 10~20Hz에서만 다시 생성해 캐시하며, 프레임 사이에는 투명도와 추적 위치만 변경합니다. 동시에 존재하는 기본 전기 효과는 최대 3개로 성능 테스트에서 제한합니다.

## 쿨타임·범위 처리 최적화

- 쿨타임 계산은 매 프레임 유지하되 HUD 상태 Signal은 최대 10Hz와 발동·준비 완료 순간에만 전송합니다.
- 기동 가속 종료는 매 프레임 감소시키는 Node 대신 one-shot `Timer`가 처리합니다.
- 자기장은 `get_children()` 임시 배열 없이 컨테이너 인덱스로 대상을 순회합니다.
- 대형 작전 프레임·Node·이펙트 예산은 [최소·권장 사양과 성능 예산](../performance/minimum-requirements.md)에서 별도로 검증합니다.

## 장비 스킬과의 관계

현재 장비 시스템의 스킬은 무기 대·중·소분류 호환성과 0~10개 장착 제한을 관리합니다. 이번 전투 스킬 세트는 조작과 효과 검증을 먼저 할 수 있도록 독립 기본 로드아웃으로 구성했습니다. 이후 장비 스킬 ID와 전투 효과 정의를 연결하면 무기 호환 결과에 따라 하단 슬롯을 교체할 수 있습니다.

## 확장 지점

- 충전 횟수, 에너지, 체력 소모 등 쿨타임 외 자원 정책
- 무기 태그에 따른 스킬 활성·비활성 연결
- 원형 자기장의 지속 피해, 끌어당김, 상태 이상
- Google Sheets 기반 스킬 수치 실시간 테스트
- 최대 HP·등급·밀집도 기반 자동 대상 정책
