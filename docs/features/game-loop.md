# 게임 루프와 HUD

## 한 판의 흐름

1. 플레이어와 활성 모듈을 설치합니다.
2. 생존 시간 측정을 시작합니다.
3. 적 생성, 자동 전투, 경험치 획득을 반복합니다.
4. 체력이 0이 되면 Scene Tree를 일시 정지합니다.
5. 생존 시간과 처치 수를 표시합니다.
6. Enter, Space 또는 버튼으로 현재 Scene을 다시 불러옵니다.

## HUD 항목

- 생존 시간
- 현재 레벨
- 적 처치 수
- 체력과 최대 체력
- 경험치와 다음 레벨 요구량
- 활성화된 모듈 목록

## 활성화와 의존성

`damage_enabled`가 접촉 피해를 허용합니다. `game_over_enabled`는 체력이 0일 때 게임 정지와 재시작 화면을 담당하며 `damage`에 의존합니다.

## 검색 별칭

UI, 체력 바, 경험치 바, 사망, 죽음, 재도전, 다시 시작, 생존 시간
