# 게임 루프와 HUD

## 한 판의 흐름

1. 소형, 중형, 대형 작전 규모를 선택합니다.
2. 선택한 맵과 플레이어, 활성 모듈을 설치합니다.
3. 적 생성, 자동 전투, 경험치 획득과 크레딧 상자 수색을 반복합니다.
4. 탈출 지점에서 `F`를 누르면 휴대 크레딧을 회수하고 종료합니다.
5. 체력이 0이 되면 작전 실패로 종료합니다.
6. 결과 화면에서 Enter 또는 버튼으로 선택 화면부터 다시 시작합니다.

## HUD 항목

- 생존 시간
- 현재 레벨
- 적 처치 수
- 체력과 최대 체력
- 경험치와 다음 레벨 요구량
- 선택한 맵 등급과 생성 방 수
- 탈출 범위에서 표시되는 F 상호작용 안내
- 현재 체력 수치·퍼센트와 위험 단계 색상
- 이번 작전에 휴대한 크레딧

## 활성화와 의존성

`damage_enabled`가 접촉 피해를 허용합니다. `game_over_enabled`는 체력이 0일 때 게임 정지와 재시작 화면을 담당하며 `damage`에 의존합니다.

## 검색 별칭

UI, 체력 바, 경험치 바, 사망, 죽음, 재도전, 다시 시작, 생존 시간, 탈출 성공, 작전 실패
