# 게임 루프와 HUD

## 한 판의 흐름

1. 소형, 중형, 대형 작전 규모를 선택합니다.
2. 9~11분 목표의 확장 맵과 플레이어, 활성 모듈을 설치합니다.
3. 장비 로드아웃의 무기 태그, 스킬 호환성, 방어구 스탯을 적용합니다.
4. 필요하면 I로 가방, U로 장비, E로 모듈·파츠를 확인하며 Q로 메인·보조 무기를 교체합니다.
5. 현재 기본 로드아웃의 `1` 점멸, `2` 원형 자기장, `3` 기동 가속을 사용하고, 확장 가능한 1~9 슬롯의 상태를 하단 HUD에서 판단합니다.
6. 맵 크기에 비례한 목표 적 수량과 유한한 묶음 증원 속에서 자동 전투, 경험치 획득과 투입 코스트 2.5~5배 목표의 자원 회수를 반복합니다.
7. 등급별 9~11분 목표 시각에 탈출 신호가 열리면 탈출 지점에서 `F`를 눌러 휴대 크레딧을 회수합니다.
8. 체력이 0이 되면 작전 실패로 종료합니다.
9. 결과 화면에서 Enter 또는 버튼으로 시작 거점에 복귀합니다.

버프 선택이나 I/U 모달로 게임이 일시정지된 동안에는 생존 시간과 탈출 카운트다운도 진행되지 않습니다.

## HUD 항목

- 생존 시간 / 목표 시간 / 탈출 신호 남은 시간
- 현재 레벨
- 적 처치 수
- 체력과 최대 체력
- 경험치와 다음 레벨 요구량
- 선택한 맵 등급과 생성 방 수
- 작전 선택 화면의 등급별 목표 적 수량 범위
- 작전별 총 적 생성 한계와 남은 생성 예산은 공개 스냅샷으로 조회 가능
- 우측 상단의 전체 지형·플레이어·탈출 위치 미니맵
- 탈출 범위에서 표시되는 F 상호작용 안내
- 현재 체력 수치·퍼센트와 위험 단계 색상
- 이번 작전에 휴대한 크레딧
- 메인·보조 무기 태그, 활성 스킬 수, 방어구 수와 방어력
- 현재 활성 무기의 특색·피해·자동 탐지 거리·밸런스 출처
- 하단 중앙의 1·2·3 스킬 이름, 설명, READY/남은 쿨타임과 진행 막대
- `LMB 기본기`, `1~9 스킬`, `Shift/Space 회피`, `Q 무기 교체`, `I 가방`, `U 장비`, `E 모듈`, `F 상호작용` 조작 안내

## 활성화와 의존성

`damage_enabled`가 접촉 피해를 허용합니다. `health_recovery_enabled`는 [부분 체력 회복](health-recovery.md)을 독립 설치하고 `combat_skills_enabled`는 [전투 스킬과 쿨타임 HUD](combat-skills.md)를 함께 설치합니다. `game_over_enabled`는 체력이 0일 때 게임 정지와 재시작 화면을 담당하며 `damage`에 의존합니다. `fog_of_war_enabled`는 플레이어 중심 월드 시야를 제한하고, `minimap_enabled`는 안개와 별개인 전체 전술 지도를 설치합니다. 장비 하위 기능의 의존성은 [캐릭터 장비와 로드아웃](character-equipment.md)에 정리되어 있습니다.
