# 전술 미니맵

## 목적

작전 투입 직후 생성된 전체 맵의 구조를 우측 상단에서 확인할 수 있게 합니다. 소형·중형·대형 모두 같은 패널 안에 비율을 유지해 맞추므로, 맵이 커져도 HUD가 화면 밖으로 커지지 않습니다.

## 표시 정보

- 청록색 영역: 이동 가능한 방과 복도
- 갈색 영역: 실내 벽과 기둥 방해물
- 밝은 초록 원: 현재 플레이어 위치
- 주황 마름모: 탈출 위치
- 흰 방향선: 플레이어가 이동 중인 방향

미니맵은 전체 지형을 보여주는 MVP 전술 지도입니다. 전장의 안개와 발견하지 않은 방 숨김은 아직 적용하지 않습니다.

## 가시성과 성능

- 250×222px 고정 패널을 우측 상단 HUD 아래에 배치합니다.
- 맵 종횡비를 유지하고 남는 공간은 중앙 정렬합니다.
- 어두운 반투명 배경과 밝은 테두리로 전투 화면과 구분합니다.
- 정적 지형은 작전 시작 시 작은 텍스처로 한 번만 만듭니다.
- 플레이어 표식은 약 12.5회/초만 다시 그려 대형 맵에서도 불필요한 셀 단위 재렌더링을 피합니다.

## 모듈 계약

맵 생성기는 `get_minimap_snapshot()`으로 셀 경계, 셀 크기, 바닥·방해물 좌표, 시작·탈출 위치의 복사본을 제공합니다. 미니맵은 맵 생성기의 방 배열이나 A* 객체를 직접 참조하지 않습니다.

최상위 `Game`은 스냅샷, 플레이어 `Node2D`, 표시할 등급 이름만 미니맵에 전달합니다. 따라서 같은 스냅샷 형태를 제공하면 맵 생성 알고리즘을 교체할 수 있습니다.

## 활성화와 제거

`FeatureManifest.minimap_enabled`로 미니맵만 켜거나 끕니다. 미니맵은 생성된 지형 정보가 필요하므로 `map_generation`에 의존합니다.

제거할 때는 먼저 Manifest에서 미니맵을 끄고 테스트한 뒤 `game/features/minimap/` 폴더를 제거합니다.
