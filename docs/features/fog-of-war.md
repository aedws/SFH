# 로그라이크 전장의 안개

## 무엇이 바뀌었나요?

2026-09-08부터 기본 시야는 **현재 보이는 곳 / 탐색했지만 지금 안 보이는 곳 / 미탐색**의 세 상태입니다. 방에 들어왔다는 이유로 방 전체를 밝히지 않습니다. 방·통로 모두 같은 원칙을 사용하므로 문턱에서 전체 화면이 켜졌다 접히는 전환이 없습니다.

| 상태 | 플레이어가 보는 것 |
|---|---|
| 현재 시야 | 주변 360도, 기본 반경 640px. 벽·기둥·닫힌 문 뒤는 차단 |
| 탐색 기억 | 이미 본 바닥·벽의 어두운 간략 지형. 적·아이템·이펙트는 보이지 않음 |
| 미탐색 | 불투명한 어두운 영역 |

뒤돌아도 시야가 회전하지 않습니다. 이동·대쉬·워프 시 현재 위치를 기준으로 갱신하고, 문을 열거나 닫으면 가만히 있어도 차폐가 바뀝니다. 막힌 대각선 모서리는 볼 수 없습니다. 경계는 보이는 셀 안쪽에서만 완화해 숨겨진 적이 비치지 않게 합니다.

여기서 ‘로그라이크 표준’은 하나의 강제 규격이 아니라 널리 쓰이는 패턴을 뜻합니다. [Roguelike Tutorials의 시야·탐색 기억 분리](https://rogueliketutorials.com/tutorials/tcod/v2/part-4/)를 기준으로 SFH의 실시간 전투에 맞췄습니다. 시야 구현은 자체 8방향 각도 그림자 스캔과 대각선 모서리 검사를 사용합니다.

## 유지되는 것

- **전체 미니맵과 M 확장 지도는 유지**합니다. 안개는 월드 전투 정보만 가립니다.
- 방 진입→적 생성→문 봉쇄→클리어→보상 규칙은 변경하지 않습니다.
- 안개가 적을 정지시키거나 자동 타겟팅 규칙을 바꾸지는 않습니다.
- 시야 제한 페널티는 반경에 적용하며 탐색 기억은 지우지 않습니다. 새 작전에서는 기억을 초기화합니다.

## 모듈 계약

| 모듈 | 책임 / 공개 계약 |
|---|---|
| 맵 생성 | `get_fog_geometry()` → 셀 크기·영역·바닥/벽 복사본 |
| 닫힌 문 | `fog_visibility_blocker` 그룹, `get_visibility_bounds()` → 실제 차폐 사각형 |
| `RoguelikeVisibilityField` | 순수 격자 FOV·탐색 기억·캐시·마스크. 월드 액터 참조 없음 |
| `RoguelikeFogRuntime` | 지형 제공자, 문 변경, 카메라 역변환, 마스크 텍스처 연결 |
| `roguelike_fog.gdshader` | 현재 시야와 불투명한 간략 지형 기억 합성. 얇은 문 뒤 추가 차폐 |
| `BattlefieldFogOfWar` | `configure()`·시야 배율·상태 진단, 기능 조립 진입점 |

`get_visibility_state()`는 **셀 단위 진단**입니다. 픽셀 경계 완화·반경 끝·얇은 문의 추가 마스크까지 포함한 AI 공격 허용 판정이 아닙니다. 전투 로직은 이 값을 사용하지 않습니다.

## 설정과 성능

`roguelike_visibility_enabled=true`, `sight_radius=640`, `fov_refresh_seconds=0.08`이 기본입니다. 셀 변경·문 개폐는 즉시 처리하고, 정지·방향 회전만으로 같은 FOV를 다시 계산하지 않습니다. 카메라와 부드러운 원형 끝 경계는 매 프레임 추적합니다.

마스크는 지형 셀당 RGBA 4바이트입니다. 격자 축당 2048셀, 계산 반경 40셀까지 제한합니다. 얇은 문 픽셀 차폐는 최대 64개이고 그 외 문도 격자 차폐에는 포함됩니다. 현재 방 전투의 소수 문 범위를 넘는 확장은 별도 예산 검증이 필요합니다.

AMD 890M 환경의 네이티브 렌더 측정(각 규모 40회): FOV CPU 중앙값 약 2.1~2.3ms, P95 약 2.3~2.5ms. 생성 맵 마스크는 해당 표본에서 약 0.39~1.10MB였습니다. 전체 게임 프레임 시간이나 평균 PC·모바일 성능 보장이 아닙니다.

지형 제공자가 없거나 기능 플래그를 끈 경우의 기존 방/정면 원뿔 구현은 **레거시 폴백**으로 보존합니다. 예전 14px 문턱·방 전체 공개·정면 각도 설정은 기본 로그라이크 모드에는 적용되지 않습니다.

## 검증과 남은 수락

`roguelike_fog_contract_test.gd`에서 벽 뒤·대각선·후방·문턱 왕복·문 개폐·워프·기억·새 작전 초기화·세 규모 실제 생성 맵을 검사합니다. 렌더 테스트는 숨겨진 액터 색을 바꿔도 기억 화면 픽셀이 동일한지, 얇은 문 뒤 픽셀이 가려지는지도 확인합니다.

CI는 헤드리스 상태 검사만으로 시각 검수를 통과시키지 않습니다. Xvfb 렌더의 `ROGUELIKE_FOG_PIXELS_OK`가 필요합니다. 전체 입력 E2E의 시야 판정도 세 상태 계약으로 교체했습니다. 배포 Web·Windows·모바일에서 10분 일반 플레이의 거리감/재미 수락은 별도 잔여입니다.
