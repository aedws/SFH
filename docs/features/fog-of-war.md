# 전장의 안개

## 현재 동작

작전이 시작되면 플레이어 주변 약 410px를 중심 시야로 확보하고, 바깥쪽은 짙은 안개로 가립니다. 150px의 부드러운 경계를 사용해 시야가 원형으로 갑자기 끊기지 않습니다.

안개는 월드 전용 `CanvasLayer`에만 표시됩니다. 상단 HUD, 상호작용 안내, U·I 화면과 우측 상단 미니맵은 가리지 않습니다.

## 미니맵과의 관계

월드 시야와 미니맵 정보는 의도적으로 분리했습니다.

- 월드: 현재 플레이어 주변만 확인
- 미니맵: 작전 시작 시 생성된 전체 방·복도·장애물·탈출 위치 유지

따라서 전투 중 시야 긴장감은 생기지만, 대형 맵에서 방향을 잃지 않고 전체 작전 경로를 계획할 수 있습니다. 미니맵에는 `FULL MAP` 표기를 표시합니다.

## 모듈 계약

`BattlefieldFogOfWar`는 `configure(actor)`로 추적할 `Node2D` 하나만 받습니다. 맵의 방 배열, 미니맵 텍스처, 플레이어 내부 이동 구현을 알지 않습니다.

`get_snapshot()`은 시야 반경, 경계 부드러움, 안개색, 추적 상태와 CanvasLayer 번호를 복사해 제공합니다. 자동 테스트는 이 계약을 사용합니다.

## 활성화와 확장

`FeatureManifest.fog_of_war_enabled`로 독립 활성화합니다. 플레이어 모듈만 의존하며 맵 생성과 미니맵은 별도로 켜고 끌 수 있습니다.

향후 장비·버프별 시야 반경, 조명탄, 적 감지 센서, 탐색 완료 영역 저장은 이 모듈의 설정과 공개 메서드 위에 추가합니다.
