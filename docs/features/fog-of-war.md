# 공간 단위 전장의 안개

**9/9 복합 구역:** [실제 바닥 마스크](extraction-district.md#compound-20260909)로 L/U/중정의 빈 부분을 방 공개에서 제외합니다. 통로에서도 다른 시설 바닥을 공개하지 않습니다. 마스크 공간은 셀 소유권으로 전환하며 아래 14px 사각형 히스테리시스는 기존 provider에만 적용됩니다. 밝기 전환·발 위치 공개는 유지합니다.

2026-09-08 오너 승인으로 [익스트랙션 구역](extraction-district.md)의 **현재 공간 전체 공개**가 기본이 됐습니다. 같은 날 먼저 적용한 360도 반경 FOV는 비교용 폴백입니다.

| 상태 | 화면에서 보이는 정보 |
|---|---|
| 현재 시설/도로 구간/진입 통로 | 해당 공간 전체와 벽 표면. 같은 시설 내부의 기둥 뒤도 공개 |
| 지나온 다른 공간 | 어두운 불투명 간략 지형. 적·전리품·이펙트는 숨김 |
| 아직 방문하지 않은 공간 | 불투명 안개. 문이 열려 있어도 다른 방은 자동 공개하지 않음 |

방에서 도로로 나가면 도로 구간만 현재 공간이 됩니다. 문턱 14px 히스테리시스로 잦은 왕복을 억제하고 새 공간은 0.22초 동안 밝아집니다. 플레이어 발 위치 셀은 경계에서도 공개합니다. 이는 Enter the Gungeon의 공간 읽기 경험을 참고한 SFH 자체 정책이지 원작 알고리즘 복제가 아닙니다.

## 유지되는 것

- 전체 미니맵과 M 지도는 항상 전체 지형을 표시합니다.
- 적 AI·타게팅·투사체 충돌은 시야 마스크와 독립입니다. 공개 공간 안의 기둥은 여전히 이동과 탄환을 막습니다.
- 일반 시설은 후퇴 가능하고 금고 단말을 선택해야 봉쇄됩니다. [교전 규칙](room-encounters.md).
- 공간 모드의 시야 제한 배율은 공간 밝기로 표현합니다(최저 45%, 임시 정책). 반경 FOV 폴백에서는 원래 반경 보정을 사용합니다.
- 새 작전에서는 탐색 기억을 초기화합니다. 안전 단말 워프는 카메라 위치도 즉시 맞춥니다.

## 모듈 계약

| 모듈 | 책임 |
|---|---|
| DistrictMapGenerator | `get_fog_geometry()`, `get_visibility_spaces()`: 지형·공간 복사본 |
| SpaceVisibilityField | 공간 판정·14px 경계 유지·현재/기억 셀. 액터 참조 없음 |
| RoguelikeFogRuntime | 카메라 역변환·문 변경·공간 전환·마스크 업로드 |
| roguelike_fog.gdshader | 현재 공간과 불투명 기억 합성. 문 픽셀 추가 차폐 |
| BattlefieldFogOfWar | configure·정책 플래그·시야 배율·진단 스냅샷 |

`get_visibility_state()`는 셀 진단이지 AI 공격 허용 API가 아닙니다. 기본값은 `roguelike_visibility_enabled=true`, `space_visibility_enabled=true`. 공간 제공자가 없거나 공간 기능만 끄면 기존 반경 640px FOV를 사용합니다. 두 기능을 끄면 더 오래된 방/정면 시야 폴백이므로 현행 기획으로 읽지 마세요.

## 성능과 검증 범위

같은 공간·같은 문 상태에서는 공개 셀을 다시 스캔하지 않습니다. 마스크는 지형 셀당 RGBA 4바이트, 축당 최대 2048셀입니다. 카메라 투영과 밝기 전환은 매 프레임 갱신합니다.

`extraction_district_contract_test.gd`와 E2E 보조 계약에서 소·중·대형의 공간 전체 공개, 이전 공간 기억, 다른 공간 미공개, 문턱 왕복 중 플레이어 공개를 검사합니다. 기존 `roguelike_fog_contract_test.gd`의 반경 FOV 성능 수치를 새 공간 알고리즘 수치로 재사용하지 않습니다. GPU 기억 불투명성·문 차폐 회귀와 실제 구역 렌더 캡처를 함께 봅니다.
