# 현장 무기 즉시 장착

## 무엇이 변했나

방 보상 무기·방어구를 `R 즉시 장착`, `F 획득·가방`, `ESC 보류`로 선택합니다. R은 슬롯·요원 태그가 맞아야 하며, 불일치 장비도 F 보관은 가능합니다. 실제 공격 수치는 Weapon Sheet/확정 CSV를 사용합니다. 모듈·파츠는 F로 가방에 넣은 뒤 I/U/E에서 호환 장비에 장착합니다.

기존 장비 처리 방식은 아직 기획 확정 전입니다. 현재는 손실을 만들지 않는 **런 임시 보관**을 사용하고 거점 복귀 직전에 원래 장비를 복구합니다. 탈출 성공이 현장 장비의 영구 해금을 뜻하지 않으며, 영구 정산은 P4-06 책임입니다.

## 데이터 연결

| 데이터 | 위치 | 책임 |
|---|---|---|
| 무기 정의·밸런스 | `Weapon` 7행 | 태그·등급·발사 수치 |
| 지역 드랍 | `LootTable` 77개 데이터 행 | 3지역 방·적·보스 출처 후보 |
| 교체 정책 | `FieldLootEquipCatalog` Resource | 대상 슬롯·기존 장비 목적지·확정 상태 |

실시간 시험 뒤 같은 스키마의 확정 CSV와 Web payload로 고정합니다. 무기이므로 `Item` 탭에 중복 등록하지 않습니다.

현재 현장 카탈로그는 무기 4종·방어구 2종·스킬 1종·모듈 4종·파츠 3종입니다. 즉시 장착 기능을 꺼도 정의 카탈로그와 F 가방 획득은 유지합니다. 반출은 수량 기반 창고 정산이며 이번 런 장비 편집 상태 전체의 영구 저장은 별도 범위입니다.

## 모듈 경계

`FieldLootEquipCatalog → FieldLootEquipService → FieldLootAcquisitionService → Game 조립`의 단방향입니다. 비교 서비스는 읽기 전용 미리보기만 만들고, 장착 서비스만 장비 상태를 변경합니다. 카탈로그 토글을 끄면 기존 F 획득·ESC 보류는 그대로 남습니다.
