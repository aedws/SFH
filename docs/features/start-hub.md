# 시작 거점과 전투 세션 전환

게임은 전체 화면 선택 메뉴 대신 이동 가능한 `SFH 전초기지`에서 시작합니다. 시작 거점은 1800×1040px 크기의 **큰 방 하나**이며 안전 구역이라 피격과 적 생성은 없습니다.

## 플레이 흐름

```text
시작 거점 이동 → 동쪽 작전 게이트 접근 → F → 전투 세션 구성
      ↑                                            ↓
      └──── 결과 확인 ← 탈출 성공 또는 사망 ← 작전 지역
```

1. 청록색 플레이어를 움직여 방 동쪽의 원형 작전 게이트로 이동합니다.
2. `F · 작전 게이트 접속`이 표시되면 F를 눌러 세션 구성 UI를 엽니다.
3. 확정 CSV/실시간 테스트 모드와 소형·중형·대형 전장을 선택합니다.
4. 거점 인스턴스를 정리하고 선택한 맵·전투·파밍 모듈만 조립합니다.
5. 탈출 또는 사망 결과 화면에서 `시작 거점으로 복귀`를 선택합니다.
6. 전투 세션의 동적 Node를 모두 정리하고 새 거점 플레이어와 큰 방을 설치합니다.

구성 UI와 `I`, `U`, `E`로 연 패널은 모두 `ESC`로 닫을 수 있습니다. 패널을 닫으면 열기 전 일시정지 상태로 정확히 돌아갑니다.

## 거점 장비 확인 단축키

| 키 | 거점 동작 | 출격 연결 |
|---:|---|---|
| `I` | 12×8 가방과 아이템 상세 확인 | `ESC`로 닫고 U/E와 상호 배타적으로 표시 |
| `U` / `E` | 무기·방어구·모듈·파츠 장착·교체·해제 | 준비 상태를 전투 세션과 귀환 후에도 유지 |
| `Q` | 메인·보조 확인 무기 전환 | 선택 슬롯을 전투 세션에 유지 |
| `F` | 작전 게이트 접속 | 작전 계약·규모 선택으로 이동 |

거점과 전투 세션은 같은 UI 모듈을 사용합니다. 장비를 교체하거나 해제하면 기존 장비와 강화 상태가 가방으로 반환되고, 모듈·파츠도 장착·교체·해제할 수 있습니다. 준비한 장비·가방 런타임 스냅샷은 거점→작전→거점 조립 경계를 넘어 유지됩니다.

## 시작 UI 최적화

- 시작 거점 HUD는 이동, `I`, `U/E`, `Q`, `F` 준비 단축키를 한 줄로 표시합니다.
- 세션 구성 UI는 전투 맵 위가 아니라 안전 구역 위에서 열리며 이동 입력을 일시 정지합니다.
- 전장 카드에는 목표 시간, 투자 표시, 방 범위를 한 번에 보여줍니다.
- 데이터 모드는 전장 카드와 분리해 실시간 테스트 여부를 명확히 확인합니다.
- 우측 상단 `ESC` 버튼과 실제 Escape 입력이 같은 닫기 계약을 사용합니다.

## 모듈 경계

`start_hub/`는 방 크기, 충돌 경계, 스폰·게이트 위치와 F 상호작용만 담당합니다. 전장 등급, 맵 생성, 적, 파밍, 장비를 알지 않습니다.

`Game`은 거점 플레이어에 장비·가방 제공자와 편집 UI를 조립합니다. `operation_requested` Signal을 받으면 준비 상태를 공개 스냅샷으로 보관하고, 거점 인스턴스를 정리한 다음 전투용 인스턴스에 복구합니다. `start_hub_enabled`를 끄면 기존처럼 작전 선택 UI에서 바로 시작할 수 있으며, `run_setup_enabled`를 끄면 설정된 기본 전장으로 즉시 진입합니다.

## 아직 구현하지 않은 것

- 거점 안의 상점·제작·보관함 NPC
- 앱 종료 뒤에도 준비 장비를 유지하는 영구 로드아웃 저장
- 보스 조건 선택
- 여러 거점 방과 장식 오브젝트
