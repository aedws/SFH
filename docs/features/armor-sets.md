# 방어구 4부위와 세트 효과

**변경 전:** 몸·발 2부위에 방탄복·전투화만 있었습니다. **변경 후:** 머리·몸·손·발 4부위와 방어구 14종을 제공합니다. 기존 두 장비와 저장 내용은 유지하고, 세트 방어구 12종을 추가했습니다.

## 1. 어떻게 쓰나요?

같은 세트의 서로 다른 부위를 **2개** 입으면 첫 보너스, **4개** 입으면 두 보너스를 함께 받습니다. 서로 다른 세트 2개씩을 입는 **2+2 조합**도 가능합니다. 가방에만 넣은 물건, 같은 부위 중복, 해제한 물건은 세트 수에 포함되지 않습니다.

거점 또는 작전 중 가방에서 장착하고, 스탯/방어구 모듈 화면에서 `활성·미충족`을 확인하세요. 편집 중에는 미리보기이며, 저장을 선택해야 실제 장비로 적용됩니다. 탈출하면 창고에 남고, 사망 시 런 획득물 소실 정책을 그대로 따릅니다.

## 2. 세트와 획득 장소

아래는 **2026-09-09 임시 밸런스**입니다. 타 게임의 고유 명칭·수치·이미지는 가져오지 않았습니다.

| 세트 | 2부위 | 4부위 추가 효과 | 주요 획득 지역 |
|---|---|---|---|
| 수호자 `bastion` | 최대 체력 ×1.12 | 방어력 +3 | 폐허 도시 |
| 질주자 `strider` | 이동 속도 ×1.08 | 활성 무기 공격 간격 ×0.90 | 산업 지구 |
| 축전자 `conduit` | 장착 스킬 쿨타임 ×0.90 | 장착 스킬 피해 ×1.20 | 연구 단지 |

각 지역의 **방 보상·보스 드랍**에서 헬멧·전투복·장갑·전투화 4종을 얻습니다. 일반 적 처치에 방어구 직접 드랍을 새로 추가하지 않았습니다. 방 보상 등급 2/가중치 12, 보스 등급 3/가중치 20이 기본이며 기존 난이도·투자 보정을 받습니다. 가중치는 확률이나 획득 보장이 아닙니다.

## 3. 개별 장비 능력치

표의 순서는 **머리 / 몸 / 손 / 발**입니다. 기본 능력치는 품질 보정을 받고, 고정 옵션과 세트 계수는 레벨·품질·모듈과 독립입니다.

| 계열 | 기본 최대 체력 추가 | 기본 방어 추가 | 기본 이동 속도 추가 | 각 부위 고정 옵션 |
|---|---|---|---|---|
| 수호자 | 8 / 20 / 5 / 5 | 1 / 3 / 1 / 1 | 0 / 0 / 0 / 0 | 방어 +0.5 |
| 질주자 | 5 / 10 / 4 / 4 | 0.5 / 1 / 0.5 / 0.5 | 2 / 3 / 2 / 6 | 이동 속도 +3 |
| 축전자 | 6 / 14 / 4 / 4 | 0.5 / 1 / 0.5 / 0.5 | 0 / 0 / 0 / 4 | 최대 체력 +3 |

신규 장비는 레벨 1~3, 모듈 2칸·코스트 6입니다. 성장 단계마다 누적 최대 체력 +0/+3/+6을 적용합니다. 최고 레벨 소켓 최적화는 기존 규칙을 따릅니다. 별도의 성유물식 재추첨/강화 재료 경제는 이번 범위에 추가하지 않았습니다.

세트의 체력 배율은 현재 합산 체력에 적용되므로 성장하면 최종 증가량은 달라지지만 **계수 ×1.12 자체는 바뀌지 않습니다**. 최대 체력 증가·장착 반복은 회복 수단이 아니며 HP 키트 규칙을 유지합니다. 질주자는 일반 공격 리듬, 축전자는 전투 스킬에 적용됩니다. 무기 고유 고정 피해는 증가시키지 않습니다. 지속 스킬은 발동 시 효과를 확정하므로 도중 장비를 바꾸어 이미 발동한 효과를 다시 계산하지 않습니다. AP 비용과 충전 회복 시간은 변경하지 않습니다.

## 4. 기획자는 어디를 고치나요?

[공유 시트](https://docs.google.com/spreadsheets/d/1dtQKVZiMf7VRFWrVnaL3BqzR0g4ZgEG6ueH9RIN3xqM/edit#gid=910909)의 행 1은 변수, 행 2는 한글 설명, 행 3부터 실제 데이터입니다.

| 탭 | 책임 | 이번 확장 |
|---|---|---|
| Armor | 이름·부위·기본 스탯·고정 옵션·`set_id` | 총 14행, P열 세트 ID |
| ArmorSet | 필요 부위 수·보정 대상·연산·수치·임시/확정 | 신규 탭 6행 |
| Upgrade | 장비별 성장 단계 | 36행 추가 |
| LootTable | 지역·출처·가중치 | 24행 추가, 총 125행 |

예: `축전자 4세트 피해 배율을 1.20→1.15로 변경 / 임시 / 장기전에서 스킬 편중을 줄이기 위한 시험`. Notion에는 대상 ID·기존값·제안값·적용 조건·이유를 쓰고 오너에게 개인 메시지로 전달하세요. 위키 초안·Notion 확정은 자동 배포가 아닙니다.

[DPS·장착 계산기](../tools/dps-lab.md)에서 방어구 4부위와 모듈을 선택하면 생존 수치, 무기 리듬, 스킬 피해/쿨타임에 반영됩니다. [성장 그래프](../tools/balance-workbench.md#growth)는 선택한 **한 방어구**의 레벨 변화를 보여줍니다. 기획자는 초안을 시험하고 개발자는 현행 또는 확정된 비교 그래프를 확인합니다.

## 5. 적용·모듈 계약

검토된 Armor/ArmorSet 값을 잠금 `armor_catalog.csv`/`armor_set.csv`에 반영한 후 `python scripts/sync_armor_catalog.py`로 검증·Resource·Web 미러를 생성합니다. `--check`는 정의/CSV 불일치를 차단합니다. Upgrade·LootTable은 기존 동기화 도구를 사용합니다. 방어구 세트의 변경은 **잠금 및 재빌드**가 필요하며 이미 실행 중인 런에 원격 시트 값을 몰래 주입하지 않습니다. 기존 라이브 시험→잠금 CSV→동일 Web/Windows 산출물 경로는 유지합니다.

`ArmorSetDefinition`은 데이터 검증, `ArmorSetResolver`는 장착 수·합산만 담당합니다. 장비 시스템이 플레이어/무기/스킬에 각 결과를 전달합니다. 새 지원 수치는 CSV로 바꾸며 새로운 발동 방식은 별도 실행 계약과 테스트를 추가합니다. 저장 복원은 허용된 Resource만 복원하고 같은 ID의 상충된 세트나 중복 슬롯은 거부합니다.
