# 탈출 방어전과 작전 결과 정산

탈출 신호가 열린 뒤 탈출 지점에서 `F`를 누르면 즉시 끝나지 않고 방어 카운트다운이 시작됩니다. 구역 밖으로 나가면 카운트다운은 취소되며 다시 `F`로 시작해야 합니다.

| 맵 | 표준 | 베테랑 | 악몽 |
|---|---:|---:|---:|
| 소형 | 15초 | 18초 | 21초 |
| 중형 | 20초 | 24초 | 28초 |
| 대형 | 25초 | 30초 | 35초 |

카운트다운 동안 기존 적 생성·증원 예산은 계속 동작합니다. `extraction_defense_enabled`를 끄면 기존 즉시 탈출 방식으로 복귀합니다.
시간표는 `ExtractionDefenseConfig` Resource라서 맵 규모별 기본 시간과 난이도 배율을 코드 수정 없이 바꿀 수 있습니다.

## 성공 정산

- 휴대 크레딧 × 지역·난이도·페널티 회수 배율을 영구 크레딧으로 저장
- 처치 12명당 고철 1개, 최소 1개를 창고로 반입
- 지역별 도면 확률 적용: 폐허 도시 1.0배, 산업 지구 1.3배, 연구 단지 1.7배
- 동일 지역·난이도·맵·페널티 조건의 랭킹에 점수 제출
- 내부 버프 수량 기반 외부 경험치 정산은 기존 성장 모듈에서 별도로 유지

실패 시 휴대 크레딧과 작전 중 획득품을 잃고 투입 비용은 반환하지 않습니다. 성공·실패 모두 결과 화면을 거쳐 시작 거점으로 돌아갑니다.

## 모듈 계약

`ExtractionZone`은 카운트다운과 구역 유지 판정만 담당합니다. `OperationResultService`는 영구 프로필·랭킹의 공개 메서드만 호출하며 맵, 적, UI 내부 상태를 읽지 않습니다.
도면 기본 확률, 지역별 도면, 처치당 고철과 최소 고철은 `OperationResultConfig`에 분리되어 있습니다.
