# 적 체력과 방어력

## 화면 표시

모든 적 머리 위에 두 개의 얇은 상태바를 표시합니다.

- 파란색: 방어력
- 빨간색: 체력

피해는 방어력을 먼저 소모하고 남은 값만 체력에 적용됩니다. 기본 적은 체력 3, 방어력 2이므로 피해 1짜리 투사체 기준 처음 두 발은 파란 막대만 감소합니다.

## 컴포넌트 구조

| 컴포넌트 | 책임 |
|---|---|
| `HealthComponent` | 최대·현재 체력, 피해, 회복, 고갈 Signal |
| `ArmorComponent` | 최대·현재 방어력, 선행 피해 흡수 |
| `EnemyStatusBars` | 두 컴포넌트의 Signal을 받아 월드 막대 다시 그리기 |

세 컴포넌트는 `game/features/enemies/components/`에 있습니다. 적 이동, 추적, 접촉 공격 코드와 체력 계산을 분리했으므로 다른 적 Scene에서도 같은 컴포넌트를 재사용할 수 있습니다.

## 기능 토글

- `enemy_armor_enabled`: 방어력 계산 활성화
- `enemy_status_ui_enabled`: 적 머리 위 상태바 표시

두 기능 모두 `enemies` 모듈에 의존합니다. 체력은 적의 처치 판정에 필요한 핵심 컴포넌트라 적 모듈 내부 필수 요소입니다.

## 검색 별칭

몬스터 체력, 적 HP, 아머, 실드, 방어도, 체력 게이지, 빨간 바, 파란 바
