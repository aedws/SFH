# Godot 설치

## 필요한 프로그램

- Godot 4.7.2 안정 버전
- Git
- 위키 실행용 Python 3

## Godot

1. [Godot 공식 다운로드](https://godotengine.org/download/windows/) 페이지를 엽니다.
2. 일반 Godot 4.7.2 Windows 빌드를 받습니다.
3. 압축을 풀고 실행 파일을 실행합니다.
4. Project Manager에서 `Import`를 선택합니다.
5. 저장소 루트의 `project.godot`을 선택합니다.

첫 작업에서는 C#이 아닌 GDScript를 사용하므로 .NET 빌드가 필요하지 않습니다.

프로젝트가 검증된 정확한 엔진 버전은 저장소 루트의 `.godot-version`에 기록합니다. 엔진을 올릴 때는 이 파일과 검증 결과를 함께 갱신합니다.

## 설치 확인

Godot 편집기에서 프로젝트 이름 `SFH`와 2D 화면이 보이면 설치가 완료된 것입니다.
