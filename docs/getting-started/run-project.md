# 프로젝트 실행

1. Godot에서 `project.godot`을 가져옵니다.
2. 우측 상단의 프로젝트 실행 버튼을 누르거나 `F5`를 누릅니다.
3. 작전 선택 화면에서 `확정 CSV` 또는 `실시간 테스트` 밸런스 모드를 선택합니다.
4. 소형, 중형, 대형 중 하나를 선택한 뒤 청록색 플레이어가 보이는지 확인합니다.
5. `WASD` 또는 방향키로 이동하고 `Shift` 또는 `Space`로 회피합니다. `Q`로 무기를 교체하며, `I`로 가방, `U`로 장비·개조 화면을 확인합니다.
6. HUD의 탈출 신호 시간을 확인하고 신호가 열린 뒤 주황색 탈출 지점에서 `F`를 누릅니다.

## 성공 기준

- 창 크기는 기본적으로 1280×720입니다.
- 상단 HUD에 체력, 경험치, 생존 시간, 레벨, 처치 수가 표시됩니다.
- 플레이어가 대각선을 포함한 8방향으로 가속·제동하며 Shift/Space 회피를 사용합니다.
- 카메라가 플레이어를 부드럽게 따라갑니다.
- 적이 플레이어 주변에서 생성되어 추적합니다.
- 무기가 가장 가까운 적에게 자동으로 발사됩니다.
- Q 키로 돌격소총 3점사와 권총 고위력 관통을 교체할 수 있습니다.
- 작전 시작 전에 확정 CSV와 Google Sheet 실시간 테스트 모드를 버튼으로 선택할 수 있습니다.
- 적 처치 후 경험치 결정이 생성됩니다.
- 32px 타일로 소형 18~24방, 중형 30~40방, 대형 45~60방이 생성됩니다.
- 얇은 벽과 갈색 충돌 방해물이 표시됩니다.
- 방해물이 짧은 내부 벽과 원형 기둥 형태로 표시됩니다.
- 적 머리 위에 빨간 체력과 파란 방어력 막대가 표시됩니다.
- 황금색 보급 상자를 `F`로 한 번만 수색할 수 있습니다.
- 획득한 크레딧이 상단 HUD에 표시됩니다.
- I 키로 서로 다른 크기의 아이템 패널이 있는 격자 가방이 열립니다.
- U 키로 무기·방어구 탭과 파츠·모듈·강화·개조 버튼이 열립니다.
- 상단 HUD에 맵 등급과 방 수가 표시됩니다.
- 초록 원은 시작점이며 탈출 지점은 잠금 중 회색, 신호 개방 후 주황색입니다.
- 피격 후 4초 동안 피해를 받지 않으면 최대 체력 65%까지 일부 회복합니다.
- 탈출 범위에서 F 안내가 나오고 `F`를 누르면 탈출 성공 화면이 표시됩니다.

## 자동 스모크 테스트

```powershell
.\scripts\test-game.cmd
```

작전 선택, 확장 맵, 9~11분 페이싱, 시간 잠금 탈출, 반응형 이동·회피, 부분 회복, 기존 전투·장비·성장 기능이 정상이라면 `SMOKE_TEST_OK`가 표시됩니다.
