# 프로젝트 실행

1. Godot에서 `project.godot`을 가져옵니다.
2. 우측 상단의 프로젝트 실행 버튼을 누르거나 `F5`를 누릅니다.
3. 소형, 중형, 대형 작전 선택 화면이 보이는지 확인합니다.
4. 등급 하나를 선택한 뒤 청록색 플레이어가 보이는지 확인합니다.
5. `WASD` 또는 방향키로 이동하고 주황색 탈출 지점에서 `F`를 누릅니다.

## 성공 기준

- 창 크기는 기본적으로 1280×720입니다.
- 상단 HUD에 체력, 경험치, 생존 시간, 레벨, 처치 수가 표시됩니다.
- 플레이어가 대각선을 포함한 8방향으로 이동합니다.
- 카메라가 플레이어를 부드럽게 따라갑니다.
- 적이 플레이어 주변에서 생성되어 추적합니다.
- 무기가 가장 가까운 적에게 자동으로 발사됩니다.
- 적 처치 후 경험치 결정이 생성됩니다.
- 32px 타일로 연결된 넓은 랜덤 방과 복도가 생성됩니다.
- 얇은 벽과 갈색 충돌 방해물이 표시됩니다.
- 상단 HUD에 맵 등급과 방 수가 표시됩니다.
- 초록 원은 시작점, 주황 원은 실제 탈출 지점입니다.
- 탈출 범위에서 F 안내가 나오고 `F`를 누르면 탈출 성공 화면이 표시됩니다.

## 자동 스모크 테스트

```powershell
.\scripts\test-game.cmd
```

작전 선택, 소·중·대형 맵, 방해물, F 탈출, 플레이어, 적 길찾기, 전투, 성장, 게임오버가 정상이라면 `SMOKE_TEST_OK`가 표시됩니다.

## 실행되지 않을 때

[문제 해결](../troubleshooting/index.md)의 `프로젝트가 실행되지 않음` 항목을 확인합니다.
