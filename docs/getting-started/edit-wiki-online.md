# 위키 수정 요청과 반영

온라인 위키의 공개 홈은 [https://sfh-dev-wiki.pages.dev/](https://sfh-dev-wiki.pages.dev/)입니다. 공개 영역은 홍보·플레이 테스트용이며 상세 문서는 역할 로그인 뒤 읽습니다. 위키는 **읽기 전용**이고 연필 아이콘이나 익명 편집을 제공하지 않습니다.

## 역할 로그인

상단 `역할 로그인`에서 기획자 또는 개발자를 선택하면 해당 역할의 보호 작업실로 이동합니다. 아이디는 `planner`, `developer`로 고정되고 초기 비밀번호는 `0000`입니다. 로그인 뒤 보호된 계정 설정에서 비밀번호만 바꿀 수 있습니다.

- 기획자 탭은 쉬운 게임 설명·완료된 플레이·남은 기획 결정·Notion/Sheet 작성 방법을 우선합니다.
- 개발자 탭은 완료 기준선·오류·다음 작업·코드 구조·원칙·E2E를 우선합니다.
- 역할 로그인은 문서 원본을 직접 수정하는 권한이 아닙니다. 아래 Notion·Sheet·PR 반영 계약은 그대로 유지됩니다.
- 초기 비밀번호나 변경된 비밀번호를 Notion, 채팅 기록, 위키 제안 초안에 다시 적지 않습니다.

## 기획자가 수정 또는 추가를 요청할 때

1. 로그인 뒤 기획자 작업실에서 `결정·데이터 요청`을 엽니다.
2. 요청 ID, 바꿀 내용, 수락 기준, 근거를 확인합니다.
3. [Notion 작성 가이드](../access/planner.md#notion-authoring)에 따라 같은 요청 ID와 `확정/임시/제안/보류/변경/검수 완료` 상태로 SFH Notion 원본에 결정을 남깁니다. 모르는 값은 `미정`으로 표시합니다.
4. `노션 최신 내용 확인 후 [요청 ID] 반영`이라고 요청합니다. AI 개발자는 공개 Notion 스냅샷을 확인하고 확정·임시·미정을 분리해 같은 요청 ID로 구현·문서·E2E를 연결합니다.
5. 완료된 변경은 작업 브랜치와 PR 검증을 거쳐 병합되며 Cloudflare 위키에 자동 배포됩니다.

위키의 링크와 설명은 원본을 직접 수정하지 않습니다. 확정 기획은 Notion·Google Sheet, 개발 변경은 작업 브랜치·PR에 남깁니다.

## 개발자가 문서를 직접 바꿀 때

권한이 있는 개발자는 비공개 원본을 로컬 작업 폴더에서 수정합니다. `main`에 직접 쓰지 않고 `codex/` 작업 브랜치에서 다음 순서를 지킵니다.

1. `docs/**/*.md`, `mkdocs.yml`, 검색 우선순위, 전체 문서 노드맵을 함께 수정합니다.
2. 일일 업데이트는 날짜당 하나의 묶음 안에 추가하고 홈에는 오늘 항목만 최신순으로 둡니다.
3. strict 위키 빌드, 링크·검색·모바일 반응형 E2E를 실행합니다.
4. 커밋·푸시·PR·필수 검사를 통과한 뒤 병합합니다.
5. Cloudflare 배포와 공개 URL을 다시 확인합니다.

작업이 끝난 뒤 바탕화면 폴더를 직접 복제해 보관하지 않습니다. 임시 worktree의 제거 조건과 커밋 기반 복구 순서는 [작업 폴더 정리와 Git 복구](source-control-and-cleanup.md)를 따릅니다.

## 변경 위치

| 목적 | 원본 |
|---|---|
| 문서 본문 | `docs/**/*.md` |
| 좌측 메뉴 | `mkdocs.yml` |
| 기본 검색 순위 | `docs/assets/search-priorities.json` |
| 전체 문서 노드맵 | `docs/assets/knowledge-map.json` |
| 기획 요청 카드 | `docs/assets/planner-requests.json` |
| 배포 게이트 | `.github/workflows/deploy-wiki.yml` |
| 역할 인증·세션 | `cloudflare/wiki-auth/_worker.js` |

게임 수치 목록이 새로 필요하면 Google Sheet의 1행 변수명·2행 설명·3행 이후 데이터 계약을 확장하고, 확정 CSV와 Web 내장 데이터도 같은 PR에서 동기화합니다.

## 배포 확인 기준

- 공개 홈은 비로그인으로 열리고 상세 문서는 비로그인 상태에서 본문을 내려주지 않습니다.
- 역할 로그인 뒤 수정한 문서와 보호 검색이 같은 배포에서 열립니다.
- 검색 결과와 전체 문서 노드맵이 새 문서를 가리키며 404가 없습니다.
- 휴대폰 360px부터 데스크톱까지 가로 넘침과 클릭 범위 교차가 없습니다.
- 브라우저 플레이와 Windows 다운로드는 같은 검증 커밋과 데이터 버전을 사용합니다.
