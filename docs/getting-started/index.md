# 시작하기

처음 프로젝트를 여는 순서는 다음과 같습니다.

1. [Godot 설치](install.md)
2. [편집기 기초](editor-basics.md)
3. [프로젝트 실행](run-project.md)

처음에는 모든 메뉴를 익히려 하지 않아도 됩니다. Scene, Node, Inspector, FileSystem, Script 패널의 역할부터 익힙니다.

[SFH 종합 문서](../features/index.md)에서 관심 있는 주제를 선택하세요. 게임을 실행하거나 개발 도구를 설치하지 않아도 문서만 읽을 수 있습니다. 자세한 [탐색·검색 사용법](search-wiki.md)과 [수정 제안 방법](edit-wiki-online.md)을 따로 제공합니다.
